# C# School API

```bash
make start   # первый запуск: .env, сборка, миграции, тестовые пользователи
make check   # все проверки перед коммитом
make help    # остальные команды
```

API — http://localhost:8290/api, проверка, что сервер жив, — http://localhost:8290/up.
Тестовый пользователь: `student@example.com` / `Password123` (вход появится с модулем Auth).
Как устроен код — `ARCHITECTURE.md`.
