# Стили и темы

Цель: цветовую схему всего приложения можно поменять или добавить одним файлом, не трогая
компоненты. Макет — [C# School — дизайн](https://claude.ai/artifact/SuAm8xzg1Wr48w7iNRkAPG).
Светлая тема `light` — основная, её цвета сняты с макета. Тёмная `dark` построена от неё.

## Три слоя

1. **Тема** — полный набор семантических цветовых токенов (включая `--color-on-accent`), `src/assets/themes/<id>.css`,
   селектор `[data-theme='<id>']`. Цвета литералами есть только здесь.
2. **Общие токены** — одинаковые во всех темах, `src/assets/tokens.css`: шрифты
   (`--font-sans`, `--font-display`, `--font-mono`), шкалы `--font-size-*`, `--space-1…7`,
   `--radius-*`, цвета редактора кода `--color-code-*` (он тёмный в любой теме).
3. **Компоненты** — только `var(--color-…)`, `var(--space-…)`, `var(--radius…)`. Цвет
   литералом в `<style>` компонента — ошибка, её ловит `src/__tests__/themes.spec.ts`.

## Правила токенов

- Токен называется по роли (`surface`, `text-muted`, `primary`, `danger-soft`), а не по цвету.
- Новый смысл — новый токен сразу во всех темах; тест проверяет одинаковый набор.
- Контраст текста — не ниже WCAG AA (4.5:1, крупный текст 3:1) в каждой теме.
- Размеры — из шкалы. Значение вне шкалы — сначала решить, добавлять ли его в шкалу.

## Новая тема

1. Файл темы: скопировать `light.css`, поменять значения.
2. Запись в `src/theme/themes.ts` и `@import` в `src/assets/main.css`.
3. Название `theme.<id>` во всех локалях. Переключатель строится из реестра сам.

## Прочее

- Тема применяется до первой отрисовки скриптом в `index.html`; его сопоставление системной
  схемы должно совпадать с `SYSTEM_THEMES`.
- Иконки — inline SVG через `BaseIcon`.
- Новая тема добавляется и в проверку скрипта `index.html` (список допустимых id).
- Отступы, радиусы и размеры шрифта — только из шкалы. Ширины контейнеров (`max-width`) и
  минимальные размеры касания (`2.75rem` = 44 px) можно писать числом.
- Шрифты Unbounded / Inter / JetBrains Mono — свои файлы (`src/assets/fonts.css`, пакеты
  Fontsource), без запросов к сторонним доменам.
