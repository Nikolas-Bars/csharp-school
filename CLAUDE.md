# C# School

Бесплатная обучающая платформа по C# в формате «теория → сразу практика» (как coddy.tech).
Цель курса — с нуля до основ C# для Unity. Курс для начинающих, в том числе подростков;
платформа открыта для всех.

Один репозиторий (https://github.com/Nikolas-Bars/csharp-school), три части — у каждой свой
CLAUDE.md, Makefile и Docker:

- `backend` — API: Laravel 12, PHP 8.3, RoadRunner, MariaDB, Redis, Sanctum.
- `frontend` — веб: Vue 3, Vite, TypeScript, Pinia, vue-i18n.
- `runner` — компилятор и запуск C# в браузере: Roslyn + .NET 10 в WebAssembly,
  внутри Web Worker. Сборка кладётся во фронт (`public/runner`).
- `content` — учебный курс файлами: теория (Markdown), задачи, проверки, эталоны и неверные
  решения (`content/README.md`). Тесты — в runner (`tests/Content.Tests`), в базу — `course:import`.

Правила (`rules/`) — в репозитории. План (`plans/`) — только на этой машине, в `.gitignore`.

## Правила (обязательные, строго)

Подробности — в `rules/`. Читать перед любой задачей.

1. **Git: никаких коммитов и пушей без явного подтверждения пользователя.** Готовлю
   изменения, показываю, что сделано, и жду «да, коммить» / «да, пушь». Каждая новая задача —
   ветка с порядковым номером 001, 002, 003…: `rules/task-branches.md`.
2. **Ревью после каждой большой задачи** — сам или независимым агентом, до предложения
   коммита. Ревью ничего не коммитит и не пушит: `rules/review.md`.
3. **Объяснять простыми словами при первом упоминании** — в уроках, подсказках, ошибках и в
   чате. Пример: «верхний регистр» — заглавные буквы (A, B, HELLO), «нижний» — строчные
   (a, b, hello); C# их различает, поэтому `hp` и `HP` — разные переменные:
   `rules/course-content.md`.
4. **Тесты на каждый урок и каждый модуль** — и для учеников (автотесты задач, проверка в
   конце урока, контрольная в конце модуля), и для самого курса (эталонное решение проходит,
   неверные падают): `rules/course-content.md`.
5. **Архитектура как на большом проекте** — модульный монолит, слои, границы модулей, строгие
   проверки. Нарушение правила — ошибка, а не стиль: `rules/architecture.md`,
   `backend/ARCHITECTURE.md`, `frontend/CLAUDE.md`.
6. **Библиотеки — самые лёгкие и быстрые среди безопасных**: `rules/dependencies.md`.
7. **Стили только через токены тем**: `rules/frontend-styles.md`.
8. **План** — `plans/plan.md`. В начале сессии читать «Статус», после каждого сдвига —
   обновлять его в том же ходе.

## Окружение

Всё запускается в Docker, на Mac не нужны PHP, Node и .NET. В каждой части свой
`Makefile` с одинаковыми командами (`make help` — список):

| Команда | Что делает |
| --- | --- |
| `make start` | Первое разворачивание: `.env`, сборка, запуск (бэкенд — ещё миграции и сидеры) |
| `make up` / `make down` / `make restart` | Запуск / остановка / перезапуск |
| `make rebuild` | Пересборка образа после изменения зависимостей или Dockerfile |
| `make logs` / `make shell` | Логи / шелл в контейнере |
| `make check` | Все проверки перед коммитом: линтеры, типы/PHPStan, тесты |

Порты (не пересекаются с artverse): API `8290`, MariaDB `33270`, Redis `6590`, веб `5390`.
Из корня папки: `make start` поднимает бэкенд, собирает runner во фронт и поднимает фронт;
`make check` проверяет все три части. У runner нет сервиса: только `start`/`build`, `test`,
`check` (сборка и тесты — в контейнере .NET SDK).

## Принятые решения

- Код учеников компилируется и выполняется в браузере ученика (Roslyn + .NET WebAssembly).
  Сервер чужой код **никогда** не выполняет.
- Код ученика — как в Unity: **C# 9, без неявных using** (`using System;` пишется явно). Доступны
  только базовые типы, Math, Console, коллекции и LINQ.
- Язык — русский, со структурой под переводы (i18n): бэкенд `lang/{ru,en}`, фронт
  `src/i18n/locales/{ru,en}.json`.
- Проверка задач — тестами; ошибки компилятора объясняются по-русски; подсказки по шагам.
- Первая итерация: движок + модуль 1 (~11 уроков основ).
- Дизайн: [C# School — дизайн](https://claude.ai/artifact/SuAm8xzg1Wr48w7iNRkAPG) — светлая тема
  основная (фон `#F5F3EE`, акцент `#5B3DF5`), тёмная построена от неё; редактор кода тёмный
  всегда; шрифты Unbounded / Inter / JetBrains Mono.
- Из других проектов (artverse и т. п.) код не переносится. Оттуда по образцу оформлены только
  контейнеры и Makefile; остальное написано под C# School. Взять что-то ещё — только по явной
  просьбе пользователя.
