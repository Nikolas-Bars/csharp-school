# Печать без перевода строки

`Console.WriteLine` после текста всегда переходит на новую строку. Есть и `Console.Write` — он
печатает, но остаётся на той же строке: следующий вывод продолжится сразу за ним.

`Console.WriteLine()` с пустыми скобками ничего не печатает, только переходит на новую строку.

```csharp
using System;

Console.Write("Здоровье: ");
Console.Write(80);
Console.WriteLine();
Console.WriteLine("Готов к бою");
```

На экране:

```text
Здоровье: 80
Готов к бою
```
