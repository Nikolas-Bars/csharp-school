# Рисуем прямоугольник

Вложенный цикл и `Console.Write` вместе рисуют картинки из символов:

```csharp
using System;

for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= 5; col++)
    {
        Console.Write("*");
    }
    Console.WriteLine();
}
```

На экране:

```text
*****
*****
*****
```

- Внутренний цикл печатает одну строку из 5 звёздочек.
- `Console.WriteLine()` после него переводит строку.
- Внешний цикл повторяет это 3 раза.

`row` — по-английски «ряд», `col` (column) — «столбец». Из рядов и столбцов клеток состоят
карты уровней во многих играх.
