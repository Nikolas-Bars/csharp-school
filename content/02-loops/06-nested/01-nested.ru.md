# Цикл в цикле

В теле цикла может стоять другой цикл — его называют **вложенным**. Внешний цикл перебирает
волны, внутренний — врагов в волне:

```csharp
using System;

for (int wave = 1; wave <= 2; wave++)
{
    Console.WriteLine($"Волна {wave}");
    for (int enemy = 1; enemy <= 3; enemy++)
    {
        Console.WriteLine($"  Враг {enemy}");
    }
}
```

На экране:

```text
Волна 1
  Враг 1
  Враг 2
  Враг 3
Волна 2
  Враг 1
  Враг 2
  Враг 3
```

Внутренний цикл проходит **целиком** на каждой итерации внешнего: 2 волны × 3 врага — 6 строк
про врагов.

У счётчиков разные имена. Второй `wave` внутри первого цикла компилятор объявить не даст: имя
уже занято.
