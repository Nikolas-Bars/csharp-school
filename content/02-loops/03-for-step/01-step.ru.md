# Шаг побольше

Шаг цикла — не обязательно `i++`. Это любая команда, которая меняет счётчик: `i += 2`,
`i += 10`.

```csharp
using System;

for (int meters = 0; meters <= 30; meters += 10)
{
    Console.WriteLine($"Пройдено {meters} м");
}
```

На экране:

```text
Пройдено 0 м
Пройдено 10 м
Пройдено 20 м
Пройдено 30 м
```

Счётчик растёт на 10: 0, 10, 20, 30. Следующее значение, 40, уже не подходит под условие
`meters <= 30`.
