# Обратный отсчёт

Счётчик может и уменьшаться. Для этого шаг — `i--`, а условие «смотрит» вниз:

```csharp
using System;

for (int i = 3; i >= 1; i--)
{
    Console.WriteLine(i);
}
Console.WriteLine("Бой!");
```

На экране — `3`, `2`, `1` и «Бой!».

Направление шага и условие должны подходить друг к другу:

- `i <= 1` вместо `i >= 1` — при `i = 3` условие ложно сразу, цикл не выполнится ни разу;
- `i++` вместо `i--` — счётчик пойдёт вверх: 3, 4, 5… Условие `i >= 1` будет верным ещё
  миллиарды итераций — практически бесконечный цикл, его остановит таймер платформы.
