# Счётчик живёт в цикле

Счётчик, объявленный в скобках `for`, существует только внутри цикла. После цикла его нет:

```text
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine(i);
}
Console.WriteLine(i);   // ошибка: имя i здесь не найдено
```

Часть программы, где переменную видно, называют её **областью видимости**. У счётчика for это
сам цикл. То же с переменными, объявленными внутри фигурных скобок — в теле цикла или в блоке
`if`: снаружи блока их не видно.

Зато имя можно взять снова в следующем цикле:

```csharp
using System;

for (int i = 1; i <= 2; i++)
{
    Console.WriteLine($"Удар {i}");
}
for (int i = 1; i <= 2; i++)
{
    Console.WriteLine($"Блок {i}");
}
```
