# for или while

Тот же цикл через while:

```csharp
using System;

int i = 1;                 // начало
while (i <= 3)             // условие
{
    Console.WriteLine($"Волна {i}");
    i++;                   // шаг
}
```

Текст после `//` — комментарий (как в первом уроке): пояснение для человека, компьютер его
пропускает. Комментарий можно писать и в конце строки с кодом.

Части те же, но у while они разбросаны по программе, а у for собраны в одной строке. Шаг
в for трудно забыть — он на виду.

Как выбрать:

- `for` — когда заранее известно, сколько раз повторять: 5 волн, 10 ударов.
- `while` — когда повторять, пока что-то не случится: пока враг жив, пока здоровье не полное.
