Чтобы получить уровень N, нужно набрать N × 150 опыта: для 1-го уровня — 150, для 2-го — 300.
Значок × здесь значит «умножить», в коде это `*`.

Опыт на уровень — `xpPerLevel = 150`, уровней — `maxLevel = 5`. С помощью цикла `for` выведи
таблицу для уровней с 1-го по maxLevel-й:

```text
Уровень 1: 150 опыта
Уровень 2: 300 опыта
Уровень 3: 450 опыта
Уровень 4: 600 опыта
Уровень 5: 750 опыта
```

Программа должна работать и при других значениях `xpPerLevel` и `maxLevel` — проверка запустит её ещё раз с другими числами.
