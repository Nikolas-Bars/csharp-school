# Цикл for

Цикл со счётчиком встречается так часто, что для него есть короткая запись — `for` («для»).
Всё, что управляет счётчиком, собрано в одной строке:

```csharp
using System;

for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"Волна {i}");
}
```

На экране — «Волна 1», «Волна 2», «Волна 3», как у цикла while из прошлого урока.

В круглых скобках — три части через точку с запятой:

- `int i = 1` — **начало**: создать счётчик. Выполняется один раз, перед циклом.
- `i <= 3` — условие продолжения. Проверяется перед каждой итерацией.
- `i++` — **шаг**: что сделать со счётчиком после каждой итерации.

Счётчик цикла по традиции называют `i` (от английского index — «номер»). Можно и понятнее:
`wave`, `level`.
