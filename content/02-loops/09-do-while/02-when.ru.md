# Когда нужен do-while

do-while удобен, когда условие зависит от того, что случилось в теле. Бросать кубик, пока не
выпадет 6: прежде чем проверять, нужно хотя бы раз бросить.

```csharp
using System;

Random random = new Random(3);
int roll;
do
{
    roll = random.Next(1, 7);
    Console.WriteLine($"Выпало {roll}");
} while (roll != 6);
Console.WriteLine("Шестёрка!");
```

На экране:

```text
Выпало 2
Выпало 5
Выпало 6
Шестёрка!
```

`roll` объявлена **до** do. Объяви её внутри тела — и в условии `while (roll != 6)` её не
будет видно: условие стоит уже за фигурной скобкой, вне области видимости тела.

Здесь `int roll;` без значения можно: тело do выполнится раньше условия и успеет положить в
`roll` число. Ошибка была бы, если бы `roll` читали до первого присваивания.
