# Переменная — до do

В прошлом примере `roll` объявлена **до** do, а не в теле. Объяви её внутри тела — и в
условии её не будет видно:

```text
do
{
    int roll = random.Next(1, 7);
} while (roll != 6);   // ошибка: имя roll здесь не найдено
```

Условие стоит уже за закрывающей фигурной скобкой — вне области видимости тела.

И ещё: `int roll;` без значения здесь можно. Тело do выполнится раньше условия и успеет
положить в `roll` число. Ошибка была бы, если бы `roll` читали до первого присваивания.
