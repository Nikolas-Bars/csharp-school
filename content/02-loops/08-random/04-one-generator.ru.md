# Один генератор на всю программу

Генератор создают один раз, до цикла, а Next вызывают в цикле:

```csharp
using System;

Random random = new Random(7);
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"Бросок {i}: {random.Next(1, 7)}");
}
```

На экране:

```text
Бросок 1: 3
Бросок 2: 6
Бросок 3: 4
```

Частая ошибка — создать генератор внутри цикла:

```text
for (int i = 1; i <= 3; i++)
{
    Random random = new Random(7);   // каждый раз новая цепочка с начала
    Console.WriteLine(random.Next(1, 7));
}
```

На каждой итерации появляется новый генератор с тем же зерном и выдаёт первое число цепочки:
`3`, `3`, `3`.
