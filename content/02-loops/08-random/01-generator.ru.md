# Генератор случайных чисел

В играх многое решает случай: урон, лут (добыча из сундуков и врагов), шанс попасть.
Случайные числа в C# выдаёт **генератор случайных чисел** — `Random`. Сначала его создают:

```csharp
using System;

Random random = new Random();
```

- `Random` — тип, как `int` или `string`. Но переменная этого типа хранит не число, а сам
  генератор — машинку, которая выдаёт числа вразнобой.
- `new Random()` — создать новый генератор. `new` значит «новый».
- Готовый генератор кладут в переменную `random` — со строчной буквы: `random` и `Random` для
  C# разные имена.
