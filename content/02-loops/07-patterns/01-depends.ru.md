# Внутренний зависит от внешнего

Граница внутреннего цикла может зависеть от счётчика внешнего. Тогда каждая строка получается
своей длины:

```csharp
using System;

for (int row = 1; row <= 4; row++)
{
    for (int col = 1; col <= row; col++)
    {
        Console.Write("*");
    }
    Console.WriteLine();
}
```

На экране:

```text
*
**
***
****
```

Условие внутреннего цикла — `col <= row`. В 1-й строке `row` равно 1 — одна звёздочка, во 2-й —
две, и так далее.

Можно пустить внешний цикл и в обратную сторону: `for (int row = 4; row >= 1; row--)` — начать
с 4, условие `row >= 1`. Тогда строки будут становиться короче.
