# Копим сумму

За 4 волны герой собрал монеты: в волне N — N × 5 монет. Сколько всего?

```csharp
using System;

int total = 0;
for (int wave = 1; wave <= 4; wave++)
{
    total += wave * 5;
}
Console.WriteLine($"Всего монет: {total}");
```

На экране — «Всего монет: 50»: 5 + 10 + 15 + 20.

Такой приём называют **накоплением**:

1. До цикла создают переменную-копилку и кладут в неё 0.
2. В теле цикла к ней прибавляют очередное значение.
3. После цикла печатают — когда всё уже сложено.
