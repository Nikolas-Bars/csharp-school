# Считаем подходящее

Сколько чисел от 1 до 20 делятся на 3 без остатка? Остаток от деления — знак `%` из первого
модуля: если `n % 3 == 0`, n делится на 3.

```csharp
using System;

int count = 0;
for (int n = 1; n <= 20; n++)
{
    if (n % 3 == 0)
    {
        count++;
    }
}
Console.WriteLine($"Подходящих чисел: {count}");
```

На экране — «Подходящих чисел: 6»: это 3, 6, 9, 12, 15, 18.

`count` — тоже счётчик, но он растёт не на каждой итерации, а только когда условие `if` верно.
Так в играх считают убитых врагов, собранные монеты, точные выстрелы.
