Эта программа должна стрелять, пока есть стрелы, но она никогда не останавливается:

```text
int arrows = 5;
while (arrows > 0)
{
    Console.WriteLine("Выстрел!");
}
```

Найди причину и напиши рабочую версию — тоже с циклом `while`. Каждый выстрел тратит одну
стрелу: выведи «Выстрел! Осталось стрел: N», где N — сколько стрел осталось после выстрела.
После цикла выведи «Стрелы кончились»:

```text
Выстрел! Осталось стрел: 4
Выстрел! Осталось стрел: 3
Выстрел! Осталось стрел: 2
Выстрел! Осталось стрел: 1
Выстрел! Осталось стрел: 0
Стрелы кончились
```

Программа должна работать и при других значениях `arrows` — проверка запустит её ещё раз с другими числами.
