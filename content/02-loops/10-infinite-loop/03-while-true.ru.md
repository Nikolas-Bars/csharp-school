# Бесконечный нарочно

Иногда бесконечный цикл пишут нарочно: `while (true)`. Условие `true` верно всегда, и выйти из
такого цикла можно только через `break`. Это удобно, когда решить, закончить ли, можно только
посередине тела:

```csharp
using System;

int goblinHp = 30;
int round = 0;
while (true)
{
    round++;
    goblinHp -= 12;
    if (goblinHp <= 0)
    {
        Console.WriteLine($"Гоблин повержен в раунде {round}");
        break;
    }
    Console.WriteLine($"Раунд {round}: у гоблина {goblinHp} HP");
}
```

На экране:

```text
Раунд 1: у гоблина 18 HP
Раунд 2: у гоблина 6 HP
Гоблин повержен в раунде 3
```

Правило: в `while (true)` обязательно есть `break`, до которого программа точно дойдёт.

Игры устроены похоже: игровой цикл повторяется, пока игрок не выйдет. В Unity такой цикл уже
написан внутри движка — он повторяется каждый кадр, то есть для каждой новой картинки на
экране, десятки раз в секунду.
