# continue: к следующей итерации

`continue` («продолжить») не выходит из цикла, а пропускает остаток тела и сразу переходит к
следующей итерации. В for перед этим выполняется шаг.

Из пяти сундуков третий пустой — его пропускаем:

```csharp
using System;

for (int chest = 1; chest <= 5; chest++)
{
    if (chest == 3)
    {
        continue;
    }
    Console.WriteLine($"Открыт сундук {chest}");
}
```

На экране — сундуки 1, 2, 4 и 5.

Разница: `break` — выйти из цикла совсем, `continue` — пропустить одну итерацию.
