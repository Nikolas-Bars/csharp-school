# break: выйти из цикла

Иногда цикл нужно закончить раньше. Команда `break` («прервать») сразу выходит из цикла, и
программа продолжает с команды после него.

Герой идёт по коридору из 10 клеток, а на 4-й — ловушка:

```csharp
using System;

for (int cell = 1; cell <= 10; cell++)
{
    if (cell == 4)
    {
        Console.WriteLine("Ловушка! Герой отступает.");
        break;
    }
    Console.WriteLine($"Клетка {cell}: чисто");
}
Console.WriteLine("Поход окончен");
```

На экране:

```text
Клетка 1: чисто
Клетка 2: чисто
Клетка 3: чисто
Ловушка! Герой отступает.
Поход окончен
```

Клетки с 5-й по 10-ю цикл уже не проверяет.
