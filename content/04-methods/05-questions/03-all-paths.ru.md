# Ответ на любой случай

Метод с типом возврата обязан ответить **всегда**, при любых значениях параметров. Вот так
нельзя:

```text
static string GetTitle(int level)
{
    if (level >= 10)
    {
        return "Мастер";
    }
}
```

Если `level` меньше 10, метод дойдёт до конца, так ничего и не вернув. Компилятор это видит и
выдаёт ошибку CS0161: метод может закончиться без `return`.

Исправить просто: поставь в конце метода `return` на случай, когда ни одно условие не
сработало. Или допиши `else` с `return` внутри.
