# Массив не копируется

Число попадает в параметр копией. А массив — нет: метод получает **тот же самый** массив. Если
поменять в нём элемент, изменение будет видно и снаружи:

```csharp
using System;

int[] team = { 50, 80 };
HealAll(team);
Console.WriteLine(team[0]);
Console.WriteLine(team[1]);

static void HealAll(int[] hp)
{
    for (int i = 0; i < hp.Length; i++)
    {
        hp[i] += 10;
    }
}
```

На экране — `60` и `90`: метод вылечил весь отряд.

Точнее, копируется не сам массив, а **ссылка** — «адрес» массива. По одному адресу метод и
основной код находят один и тот же массив. Но если внутри метода положить в параметр другой
массив, снаружи останется старый.

Иногда это и нужно, как здесь. Но если метод должен только читать массив — посчитать сумму или
найти максимум, — элементы в нём лучше не менять.
