# Тип ответа

Метод может возвращать значение любого типа. Тип пишут перед именем:

- `static int CalculateDamage(…)` — целое число;
- `static double GetSpeed(…)` — дробное;
- `static string GetTitle(…)` — текст;
- `static bool IsAlive(…)` — `true` или `false`.

`return` должен отдать значение именно этого типа. Компилятор за этим строго следит:

- в методе с типом `int` нет `return` — ошибка: метод обязан вернуть значение;
- в методе `void` написано `return 5;` — ошибка: такой метод ничего не возвращает;
- `int x = BattleCry();` — ошибка: `BattleCry` — `void`, класть в `x` нечего.

Запомни: `void` — метод **делает** (печатает, кричит), тип перед именем — метод **отвечает**.
