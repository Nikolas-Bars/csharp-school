# Объявляем метод

Вот метод, который печатает боевой клич:

```csharp
using System;

static void BattleCry()
{
    Console.WriteLine("За короля!");
    Console.WriteLine("Вперёд!");
}
```

Разберём по частям:

- `BattleCry` — имя метода. По нему метод потом и зовут.
- `()` — круглые скобки после имени обязательны. Пока они пустые, а что в них пишут, узнаешь
  в следующем уроке.
- `void` («войд», по-английски «пустота») — метод ничего не отдаёт в ответ, а просто
  выполняет команды. Методы, которые отвечают числом, как `Math.Max`, тоже научимся писать.
- `static` («статик») — пока просто пиши `static` перед каждым своим методом. Что это слово
  значит, разберём в уроке про область видимости.
- В фигурных скобках — **тело метода**: команды, которые он выполняет.

Написать такой метод — значит **объявить** его. Само объявление ничего не печатает: это только
описание способности.
