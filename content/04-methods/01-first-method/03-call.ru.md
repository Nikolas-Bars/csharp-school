# Вызываем метод

Чтобы метод сработал, его **вызывают**: пишут имя, круглые скобки и точку с запятой —
`BattleCry();`. Так же, как `Console.WriteLine(…)`, только без `Console.` впереди.

```csharp
using System;

Console.WriteLine("Начинается бой.");
BattleCry();
Console.WriteLine("Начинается второй бой.");
BattleCry();

static void BattleCry()
{
    Console.WriteLine("За короля!");
    Console.WriteLine("Вперёд!");
}
```

На экране:

```text
Начинается бой.
За короля!
Вперёд!
Начинается второй бой.
За короля!
Вперёд!
```

Команды вне методов — это **основной код**: с него программа начинается и идёт сверху вниз.
Дойдя до `BattleCry();`, она «заходит» в метод, выполняет его тело и возвращается к строке
после вызова.
