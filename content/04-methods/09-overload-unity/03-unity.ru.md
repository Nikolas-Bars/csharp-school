# Что ждёт в Unity

В Unity скрипт — это класс, а в нём методы. Два из них встретятся тебе в первый же день:

```text
void Start()
{
    // выполняется один раз, когда объект появляется в игре
}

void Update()
{
    // выполняется каждый кадр
}
```

**Кадр** — одна картинка на экране. Игра рисует их десятки раз в секунду, и перед каждой
вызывается `Update`.

Эти методы ты не вызываешь сам — их вызывает Unity в нужный момент. А внутри пишешь то же, что
и здесь: переменные, условия, циклы и вызовы своих методов вроде `Attack()` или `IsAlive(hp)`.
Объявление, параметры, `return`, имена в PascalCase — всё это там работает так же.
