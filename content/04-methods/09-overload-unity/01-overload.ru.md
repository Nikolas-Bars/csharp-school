# Перегрузка

`Console.WriteLine` ты вызываешь с разными значениями: с числом, строкой, `bool`. На самом деле
это не один метод, а несколько методов с одинаковым именем — у каждого свой тип параметра. Так
же и `Math.Max` есть для `int` и для `double`:

```csharp
using System;

Console.WriteLine(Math.Max(3, 8));
Console.WriteLine(Math.Max(2.5, 1.5));
```

На экране — `8` и `2.5`.

Несколько методов с одним именем, но разными параметрами — это **перегрузка**. Компилятор сам
выбирает нужный по аргументам: для двух `int` — версию для `int`, для двух `double` — версию
для `double`.

Имя метода вместе со списком типов его параметров называют **сигнатурой**. У `Max(int, int)`
и `Max(double, double)` сигнатуры разные — поэтому они и могут жить рядом.
