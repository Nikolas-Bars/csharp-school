# Параметр — это копия

Когда в метод передают число или `bool`, в параметр кладётся **копия** значения. Меняя
параметр, метод меняет только копию:

```csharp
using System;

int hp = 100;
Hit(hp);
Console.WriteLine($"Снаружи: {hp}");

static void Hit(int hp)
{
    hp -= 30;
    Console.WriteLine($"В методе: {hp}");
}
```

На экране:

```text
В методе: 70
Снаружи: 100
```

Параметр `hp` и переменная `hp` основного кода — разные переменные, хоть и с одним именем: у
каждой своя область видимости.

Со строкой снаружи тоже ничего не поменяется. Строку нельзя изменить, только заменить другой
(вспомни `name = name.ToUpper();`), а замена попадает только в параметр — поэтому снаружи
строка прежняя.

Чтобы здоровье правда уменьшилось, метод возвращает новое значение, а основной код кладёт его
обратно: `hp = TakeDamage(hp, 30);`.
