# Где видна переменная

Переменная, объявленная внутри метода, существует только в нём. Снаружи её не видно:

```text
using System;

Loot();
Console.WriteLine(gold);    // ошибка CS0103: имя gold не найдено

static void Loot()
{
    int gold = 50;
    Console.WriteLine(gold);
}
```

Часть программы, где имя видно, называется **областью видимости**. Для переменной из метода
это место от её объявления до конца блока `{ }`, в котором она объявлена. Метод закончил
работу — и его переменных больше нет.

Это даже удобно: в разных методах переменные можно называть одинаково, и они не мешают друг
другу. А если значение нужно снаружи — метод отдаёт его через `return`.
