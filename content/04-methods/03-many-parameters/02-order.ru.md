# Порядок аргументов

Аргументы раскладываются по параметрам **по порядку**: первый аргумент — в первый параметр,
второй — во второй.

Если перепутать аргументы разных типов, компилятор заметит: `Hit(12, "Гоблин")` — ошибка,
число нельзя положить в параметр-строку `target`.

А вот одинаковые типы он не различит:

```csharp
using System;

ShowStats(100, 40);
ShowStats(40, 100);

static void ShowStats(int hp, int mana)
{
    Console.WriteLine($"Здоровье: {hp}, мана: {mana}");
}
```

На экране:

```text
Здоровье: 100, мана: 40
Здоровье: 40, мана: 100
```

Для C# оба вызова правильные. Но если имелись в виду 100 здоровья и 40 маны, второй вызов —
ошибка: значения поменялись местами. Поэтому сверяйся с объявлением метода — в каком порядке
там идут параметры.
