# Слово this

Параметры конструктора удобно называть так же, как поля: `name` и `hp`. Но внутри конструктора
имя `hp` тогда значит параметр — он «закрывает» поле с тем же именем. Запись `hp = hp;` кладёт
параметр сам в себя, а поле остаётся `0`. Компилятор выдаст на это **предупреждение** (CS1717) —
подсказку о подозрительном месте: программа запустится, но работать будет не так, как задумано.

Чтобы указать именно на поле, пишут `this` («зис», по-английски «этот»). `this` — сам объект,
который сейчас создаётся или у которого вызван метод:

```csharp
using System;

Hero hero = new Hero("Артур", 100);
Console.WriteLine($"{hero.name}: {hero.hp} HP");

class Hero
{
    public string name;
    public int hp;

    public Hero(string name, int hp)
    {
        this.name = name;
        this.hp = hp;
    }
}
```

На экране:

```text
Артур: 100 HP
```

`this.hp` — поле объекта, `hp` — параметр. Читается так: «положи в моё поле `hp` то, что
пришло в параметре `hp`». Так пишут конструкторы обычных классов. У скриптов Unity конструктора
нет — об этом в конце модуля.
