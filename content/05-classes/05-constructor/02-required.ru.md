# Без аргументов — нельзя

Раньше мы писали `new Hero()` без аргументов, хотя конструктора не объявляли. Дело в том, что
если в классе нет ни одного конструктора, C# сам добавляет пустой — без параметров. Его и
вызывал `new Hero()`.

Как только ты объявляешь свой конструктор с параметрами, пустой больше не добавляется:

```text
Hero hero = new Hero();    // ошибка CS7036: не хватает аргумента для параметра heroName
```

И это хорошо: героя без имени и здоровья теперь не создать по ошибке. Компилятор требует
передать всё, что просит конструктор.

Если конструктор написать с типом — `public void Hero(…)`, — это уже не конструктор, а обычный
метод с именем класса. Компилятор выдаст сразу две ошибки: CS1729 там, где пишешь
`new Hero("Артур", 100)` (конструктора с такими параметрами нет), и CS0542 у самого метода (имя
класса занято). Убери `void`.
