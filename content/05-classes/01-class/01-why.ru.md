# Зачем нужны классы

У героя в игре есть имя, здоровье и сила атаки. Пока что всё это хранится в отдельных
переменных:

```csharp
using System;

string heroName = "Артур";
int heroHp = 100;
int heroAttack = 15;

string friendName = "Мира";
int friendHp = 80;
int friendAttack = 20;

Console.WriteLine($"{heroName}: {heroHp} HP, атака {heroAttack}");
Console.WriteLine($"{friendName}: {friendHp} HP, атака {friendAttack}");
```

На экране:

```text
Артур: 100 HP, атака 15
Мира: 80 HP, атака 20
```

Два героя — уже шесть переменных. А если героев десять и у каждого ещё мана, уровень и оружие?
Легко перепутать, где чьё здоровье.

Удобнее собрать всё про героя в одно целое. Для этого в C# есть **классы**. Класс — это
описание: какие данные есть у героя и что он умеет делать. Как чертёж в кузнице: по одному
чертежу меча можно выковать сколько угодно мечей.

Каждый герой, сделанный по такому чертежу, — **объект**. Класс `Hero` один, а объектов-героев
может быть сколько угодно: Артур, Мира и ещё десяток.
