# Класс и объект в коде

Вот чертёж героя — класс `Hero` — и герой, созданный по нему:

```csharp
using System;

Hero hero = new Hero();
hero.name = "Артур";
hero.hp = 100;
Console.WriteLine($"{hero.name}: {hero.hp} HP");

class Hero
{
    public string name;
    public int hp;
}
```

На экране:

```text
Артур: 100 HP
```

Сначала — чертёж внизу:

- `class Hero` — объявление класса с именем `Hero`. Классы называют, как и методы, с заглавной
  буквы: `Hero`, `Enemy`, `MagicSword`. Объявленный класс — новый **тип**, как `int` или
  `string`, только свой.
- `name` и `hp` — **поля**: переменные, которые живут внутри объекта. У поля есть тип и имя.
  В обычном C# открытые поля пишут с заглавной (`Name`), а в скриптах Unity — с маленькой
  (`name`, `speed`). Мы пишем поля как в Unity.
- `public` («паблик», по-английски «открытый») — поле видно снаружи класса: основной код может
  его читать и менять. Подробно о нём будет отдельный урок, а пока пиши `public` перед полем.

Теперь — основной код:

- `Hero hero = new Hero();` — `new` («нью», «новый») создаёт объект по чертежу и кладёт его в
  переменную `hero` типа `Hero`. Круглые скобки обязательны. C# различает заглавные и строчные
  буквы, поэтому `hero` и `Hero` — разные имена.
- Точка открывает объект: `hero.name` — поле `name` именно этого героя. Через точку поле и
  читают, и меняют — как обычную переменную.

Объект ещё называют **экземпляром** класса — одним предметом из многих, сделанных по одному
образцу. `new` тебе уже знаком: `new Random()` и `new List<int>()`. `Random` и `List` — тоже
классы, только готовые: их уже написали за тебя.
