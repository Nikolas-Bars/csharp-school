# Ловушка с точкой с запятой

После `if (…)` точку с запятой не ставят. Она обрывает `if`: условие проверится, но ничего
не решит, а блок ниже станет обычными командами и выполнится всегда. Компилятор такое
пропустит, но предупредит (CS0642):

```text
int hp = 100;
if (hp <= 0);            // лишняя ;
{
    Console.WriteLine("Герой повержен!");   // напечатается, хотя hp = 100
}
```

Ещё про запись: команды внутри блока пишут с **отступом** — пустым местом в начале строки,
обычно четыре пробела. Компьютеру всё равно, а человеку сразу видно, что относится к `if`.
