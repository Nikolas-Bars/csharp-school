# Если…

Часто команду нужно выполнить не всегда, а только при **условии**: «если здоровье кончилось —
конец игры». Для этого есть `if` («если»):

```csharp
using System;

int hp = 0;
if (hp <= 0)
{
    Console.WriteLine("Герой повержен!");
}
Console.WriteLine("Игра продолжается.");
```

- В круглых скобках — условие, то есть сравнение или `bool`.
- В фигурных скобках `{ }` — **блок**: команды, которые выполнятся, только если условие `true`.
- Команды после блока выполняются всегда.

Здесь `hp` равно 0, поэтому на экране — обе строки.

После `if (…)` точку с запятой не ставят: она оборвала бы `if`, и блок выполнялся бы всегда.

Команды внутри блока пишут с отступом — четырьмя пробелами слева. Компьютеру всё равно, а
человеку сразу видно, что относится к `if`.
