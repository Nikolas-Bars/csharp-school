# …иначе

Чтобы сделать что-то другое, когда условие ложно, после блока `if` пишут `else` («иначе»):

```csharp
using System;

int gold = 30;
int price = 50;
if (gold >= price)
{
    Console.WriteLine("Покупка!");
}
else
{
    Console.WriteLine("Не хватает золота.");
}
```

Напечатается «Не хватает золота.». Выполняется ровно один из двух блоков: или `if`, или `else`.

Переменная `bool` — уже готовое условие: `if (isAlive)` значит «если жив».
