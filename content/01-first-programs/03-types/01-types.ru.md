# Четыре главных типа

Тип говорит, какое значение лежит в переменной. Для начала хватит четырёх:

- `int` — целое число: уровень, монеты, здоровье. `int level = 3;`
- `double` — дробное число: скорость, вес. Дробную часть отделяют **точкой**: `2.5`, а не `2,5`.
- `string` — строка, то есть текст. Всегда в кавычках: `"Аня"`. Не путай: «строкой» ещё
  называют линию текста на экране. Что имеется в виду, обычно понятно по смыслу.
- `bool` — «да или нет»: только `true` (истина, да) или `false` (ложь, нет). Без кавычек.

```csharp
using System;

int level = 3;
double speed = 2.5;
string heroName = "Аня";
bool isAlive = true;

Console.WriteLine(level);
Console.WriteLine(speed);
Console.WriteLine(heroName);
Console.WriteLine(isAlive);
```

На экране:

```text
3
2.5
Аня
True
```

`true` при выводе пишется с заглавной буквы — `True`. Так C# печатает значения `bool`.
