# Считаем

С числами можно считать: `+` — сложить, `-` — вычесть, `*` — умножить, `/` — разделить. Эти
знаки называют **операторами**.

```csharp
using System;

int attack = 12;
int bonus = 3;
int total = attack + bonus;

Console.WriteLine(total);
Console.WriteLine(attack * 2);
Console.WriteLine(2 + 3 * 4);
Console.WriteLine((2 + 3) * 4);
```

На экране:

```text
15
24
14
20
```

Как в математике, умножение и деление выполняются раньше сложения и вычитания: `2 + 3 * 4` —
это 2 + 12. Чтобы сначала сложить, возьми сложение в круглые скобки.
