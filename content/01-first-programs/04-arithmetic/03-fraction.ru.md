# Дробный результат и деление на ноль

Если хотя бы одно число дробное, результат тоже дробный:

```csharp
using System;

Console.WriteLine(7.0 / 2);
double half = 7 / 2;
Console.WriteLine(half);
```

На экране — `3.5` и `3`. Во второй строке оба числа целые: сначала `7 / 2` делится нацело и
получается 3, и только потом это 3 попадает в `double`.

Делить целое число на ноль нельзя. Если написать ноль прямо в коде — `7 / 0`, — компилятор
сразу покажет ошибку. А если делитель лежит в переменной и во время работы программы
оказался равен 0, программа остановится с ошибкой.
