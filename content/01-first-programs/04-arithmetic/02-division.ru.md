# Деление целых чисел

Когда делят два `int`, результат тоже целый — дробная часть просто **отбрасывается**:
`7 / 2` даёт 3, а не 3.5.

Что осталось «лишним», показывает знак `%` — **остаток от деления**: `7 % 2` даёт 1. Он
выполняется так же рано, как `*` и `/`.

```csharp
using System;

Console.WriteLine(7 / 2);
Console.WriteLine(7 % 2);
Console.WriteLine(7.0 / 2);
```

На экране — `3`, `1` и `3.5`. Если хотя бы одно число дробное (`7.0`), результат тоже дробный.
А `double half = 7 / 2;` — это 3: целые числа делятся раньше, чем результат попадает в
`double`.

Пример из игры: 17 стрел, в колчан входит 5. Полных колчанов — `17 / 5`, то есть 3, а стрел
останется `17 % 5`, то есть 2.

Делить целое число на ноль нельзя: программа остановится с ошибкой.
