# Или

`||` — «или»: условие верно, если верна **хотя бы одна** часть.

```csharp
using System;

int hp = 80;
bool isNight = true;
if (isNight || hp < 30)
{
    Console.WriteLine("Лучше отдохнуть в таверне.");
}
```

Здоровья много, но сейчас ночь — одной верной части хватает, сообщение напечатается.

Знак `|` — вертикальная черта. Её клавиша обычно рядом с Enter: нажми её с Shift, в английской
раскладке.
