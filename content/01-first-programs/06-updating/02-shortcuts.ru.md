# Короткие записи

Писать имя переменной дважды приходится так часто, что для этого есть сокращения:

- `hp -= 20;` — то же, что `hp = hp - 20;`
- `gold += 50;` — то же, что `gold = gold + 50;`
- `damage *= 2;` — то же, что `damage = damage * 2;`
- `level++;` — увеличить на 1, `lives--;` — уменьшить на 1.

```csharp
using System;

int hp = 90;
hp -= 20;
Console.WriteLine(hp);

int level = 1;
level++;
Console.WriteLine(level);
```

На экране — `70` и `2`.

Смотри на порядок знаков: `-=`. Если написать `hp =- 20;`, получится `hp = -20;` — в `hp`
положат минус двадцать.
