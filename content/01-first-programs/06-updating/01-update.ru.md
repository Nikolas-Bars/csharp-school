# Новое значение из старого

Герой получил урон 10. Новое здоровье — это старое минус 10:

```csharp
using System;

int hp = 100;
hp = hp - 10;
Console.WriteLine(hp);
```

Напечатается `90`. Строку `hp = hp - 10;` компьютер выполняет так: сначала считает правую
часть (100 - 10), а потом кладёт результат обратно в `hp`.

Так в играх меняется почти всё: здоровье, монеты, опыт, патроны.
