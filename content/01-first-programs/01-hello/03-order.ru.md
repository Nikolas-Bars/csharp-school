# Команды по порядку

Программа выполняет команды **сверху вниз**, по одной. Каждая `Console.WriteLine` печатает
свою строку, следующая начинается с новой строки:

```csharp
using System;

Console.WriteLine("Герой входит в подземелье.");
Console.WriteLine("Из темноты выходит гоблин!");
```

На экране будет:

```text
Герой входит в подземелье.
Из темноты выходит гоблин!
```

Поменяешь строки местами — поменяется и порядок на экране.
