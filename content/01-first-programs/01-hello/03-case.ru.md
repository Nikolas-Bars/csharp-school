# Буква в букву

C# различает **регистр** — заглавные буквы (A, B, HELLO) и строчные (a, b, hello). Поэтому
`Console` и `console` для него — разные слова, и `console.WriteLine` компилятор не поймёт.
Пиши команды точно как в примере.

Строка, которая начинается с `//`, — **комментарий**: заметка для человека. Компьютер её
пропускает:

```csharp
using System;

// Это комментарий: компьютер его пропустит
Console.WriteLine("А это команда");
```

На экране — только «А это команда». В задачах комментарием помечено место, где писать код:
`// Напиши здесь команду вывода`.
