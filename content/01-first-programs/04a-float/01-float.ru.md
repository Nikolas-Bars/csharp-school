# float — дробные числа Unity

Ты уже знаешь `double` — дробное число. В Unity почти все дробные числа другого типа —
`float`: скорость героя, его место на карте, `Time.deltaTime` — сколько секунд прошло с
прошлого **кадра**, то есть с прошлой картинки на экране. У `float` меньше значащих цифр —
тех, что число хранит точно: около 7 против 15–16 у `double`. Зато он занимает меньше памяти,
а играм такой точности хватает.

У дробного числа типа `float` в конце пишут букву `f`:

```csharp
using System;

float speed = 2.5f;
float jump = 1.2f;
float seconds = 2f;
Console.WriteLine(speed + jump);
```

Напечатается `3.7`. `2f` — это число 2, записанное как `float`. Целое число в `float` можно
положить и без буквы: `float seconds = 2;` — тоже правильно.

Без `f` дробное число `2.5` считается `double`, и строку `float speed = 2.5;` компилятор не
пропустит — ошибка CS0664.

Дробные числа хранятся приближённо: `1.1f * 3` напечатает `3.3000002`, а не 3.3. Это не ошибка
программы — так компьютер хранит дроби.
