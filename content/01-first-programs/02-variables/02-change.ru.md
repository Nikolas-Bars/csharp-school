# Значение можно поменять

Потому переменная так и называется: её значение может меняться.

```csharp
using System;

int hp = 100;
Console.WriteLine(hp);
hp = 75;
Console.WriteLine(hp);
```

На экране будет `100`, а потом `75`.

**Объявить** переменную — написать её тип и имя (`int hp`) — можно только один раз. Дальше к
ней обращаются просто по имени, без `int`: `hp = 75;`.

Правила для имён:

- латинские буквы и цифры, без пробелов, не с цифры;
- регистр важен: `hp` и `HP` — разные переменные (заглавные и строчные буквы C# различает);
- принято начинать со строчной буквы, а следующие слова — с заглавной: `maxHp`, `heroName`.
  Такой стиль называют «верблюжьим» (camelCase): заглавные буквы торчат, как горбы.
