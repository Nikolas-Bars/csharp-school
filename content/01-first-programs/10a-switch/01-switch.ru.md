# switch: выбор по значению

Когда одну переменную сравнивают с несколькими точными значениями, цепочку `else if` можно
заменить на `switch` («переключатель»):

```csharp
using System;

int floor = 2;
switch (floor)
{
    case 1:
        Console.WriteLine("Подвал с крысами");
        break;
    case 2:
        Console.WriteLine("Зал с гоблинами");
        break;
    default:
        Console.WriteLine("Пустой этаж");
        break;
}
```

Напечатается «Зал с гоблинами».

- `switch (floor)` — какое значение проверяем.
- `case 2:` («случай») — вариант «если floor равно 2». После двоеточия — его команды.
- `break;` («прервать») — конец варианта: программа выходит из switch. В C# он обязателен в
  конце каждого варианта, без него компилятор выдаст ошибку.
- `default:` («по умолчанию») — для всех остальных значений, как `else`. Его можно не писать.

Если у нескольких значений одни и те же команды, `case` можно поставить подряд — без команд
между ними: `case 3: case 4:` и дальше общие команды и `break;`.
