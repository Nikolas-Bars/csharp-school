# Склеиваем текст

Строки можно склеивать знаком `+`. К строке можно приклеить и число — оно станет текстом:

```csharp
using System;

string heroName = "Аня";
int hp = 100;
Console.WriteLine("Герой: " + heroName);
Console.WriteLine("Здоровье: " + hp);
```

На экране:

```text
Герой: Аня
Здоровье: 100
```

Обрати внимание на пробел после двоеточия внутри кавычек: без него получилось бы
`Герой:Аня`.

Осторожно: `"1" + 2` — это не 3, а `"12"`. Если хоть с одной стороны от `+` строка, он
склеивает, а не складывает.

Поэтому `"Не хватает: " + maxHp - hp` — ошибка: сначала склеится текст, а из текста вычитать
нельзя. Вычисление берут в скобки: `"Не хватает: " + (maxHp - hp)`.
