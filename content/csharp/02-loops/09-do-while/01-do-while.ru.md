# Сначала сделать, потом проверить

У while условие проверяется **до** тела. У цикла `do-while` («делай… пока») — **после**:

```csharp
using System;

int hp = 0;
do
{
    Console.WriteLine("Герой делает ход");
} while (hp > 0);
```

Напечатается «Герой делает ход» — один раз, хотя `hp > 0` неверно с самого начала. Сначала
выполняется тело, потом проверяется условие; если оно верно — тело выполняется снова.

Так что тело do-while выполняется **хотя бы один раз**. А обычный `while (hp > 0)` здесь не
выполнил бы его ни разу.

После `while (…)` в конце do-while ставят точку с запятой — в отличие от обычного while.
