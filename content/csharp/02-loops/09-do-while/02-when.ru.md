# Когда нужен do-while

do-while удобен, когда условие зависит от того, что случилось в теле. Бросать кубик, пока не
выпадет 6: прежде чем проверять, нужно хотя бы раз бросить.

```csharp
using System;

Random random = new Random(3);
int roll;
do
{
    roll = random.Next(1, 7);
    Console.WriteLine($"Выпало {roll}");
} while (roll != 6);
Console.WriteLine("Шестёрка!");
```

На экране:

```text
Выпало 2
Выпало 5
Выпало 6
Шестёрка!
```

Каждая итерация — бросок. Шестёрка выпала на третьем броске, условие `roll != 6` стало ложным,
и цикл закончился.
