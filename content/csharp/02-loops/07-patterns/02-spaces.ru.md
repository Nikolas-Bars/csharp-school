# Пробелы — тоже символы

Чтобы сдвинуть символ вправо, перед ним печатают пробелы. Это ещё один внутренний цикл:

```csharp
using System;

for (int row = 1; row <= 3; row++)
{
    for (int space = 1; space <= row - 1; space++)
    {
        Console.Write(" ");
    }
    Console.WriteLine("*");
}
```

На экране:

```text
*
 *
  *
```

В 1-й строке пробелов `row - 1`, то есть 0, во 2-й — один, в 3-й — два. Каждая звёздочка
сдвигается на одну позицию дальше.

Если после пробелов нужно несколько символов — поставь за циклом пробелов второй внутренний
цикл. В теле внешнего цикла тогда два цикла подряд, а потом `Console.WriteLine()`:

```text
for (…строки…)
{
    for (…пробелы…) { Console.Write(" "); }
    for (…символы…) { Console.Write("*"); }
    Console.WriteLine();
}
```

На экране пробелы не видны, но проверка задач их считает: пробелы в начале строки важны.
