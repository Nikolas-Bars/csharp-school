# Шаг за шагом

Вот как компьютер выполняет цикл из прошлого примера:

1. `wave` равно 1. Проверка: 1 <= 3 — верно. Печать «Волна 1», `wave` становится 2.
2. 2 <= 3 — верно. Печать «Волна 2», `wave` становится 3.
3. 3 <= 3 — верно. Печать «Волна 3», `wave` становится 4.
4. 4 <= 3 — неверно. Цикл закончен, программа переходит к команде после него.

Условие проверяется **перед** каждой итерацией. Если оно неверно с самого начала, тело не
выполнится ни разу:

```csharp
using System;

int wave = 10;
while (wave <= 3)
{
    Console.WriteLine($"Волна {wave}");
    wave++;
}
Console.WriteLine("Готово");
```

Напечатается только «Готово»: 10 <= 3 — неверно уже при первой проверке.
