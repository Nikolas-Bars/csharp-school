# Цикл while

`while` («пока») повторяет блок команд, пока условие верно:

```csharp
using System;

int wave = 1;
while (wave <= 3)
{
    Console.WriteLine($"Волна {wave}");
    wave++;
}
Console.WriteLine("Волны кончились!");
```

На экране:

```text
Волна 1
Волна 2
Волна 3
Волны кончились!
```

- В круглых скобках — **условие продолжения**: пока оно `true`, цикл делает ещё одну итерацию.
  Пишется так же, как условие у `if`.
- В фигурных скобках — **тело цикла**: команды, которые повторяются на каждой итерации.
- `wave` — **счётчик**: переменная, которая считает итерации. `wave++` в теле увеличивает его
  на 1.
