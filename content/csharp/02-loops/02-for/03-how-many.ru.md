# Сколько раз?

Программисты часто считают не с 1, а с 0: так удобно для массивов — увидишь в модуле про
массивы.

```csharp
using System;

for (int i = 0; i < 4; i++)
{
    Console.WriteLine(i);
}
```

На экране — `0`, `1`, `2`, `3`: четыре итерации. При `i = 4` условие `i < 4` уже неверно.

Оба варианта повторяют тело N раз:

- от 1: `for (int i = 1; i <= N; i++)` — счётчик 1, 2, … N;
- от 0: `for (int i = 0; i < N; i++)` — счётчик 0, 1, … N - 1.

Частая ошибка — смешать их: `i = 0` и `i <= N` дают на одну итерацию больше, а `i = 1` и `i < N` —
на одну меньше. Прежде чем запускать, проверь первое и последнее значение счётчика.
