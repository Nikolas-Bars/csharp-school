# Просим число: Next

Число у генератора просят методом `Next` («следующее»):

```csharp
using System;

Random random = new Random();
int roll = random.Next(1, 7);
Console.WriteLine($"Выпало: {roll}");
```

`random.Next(…)` — вызов метода у переменной: её имя, точка, имя метода и скобки. Так ты
просишь у генератора `random` следующее случайное число.

Next возвращает целое число, поэтому его можно положить в переменную `int`. Число случайное и
от запуска к запуску может меняться. Что значат 1 и 7 в скобках — на следующем экране.
