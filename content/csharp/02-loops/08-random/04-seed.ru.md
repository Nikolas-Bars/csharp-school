# Зерно

На самом деле генератор не гадает, а считает числа по формуле. Формула начинает с одного
числа — его называют **зерном**. Из одного зерна «вырастает» всегда одна и та же цепочка
чисел.

`new Random()` без числа в скобках выбирает зерно сам, поэтому каждый запуск разный. А если
написать зерно, например `new Random(42)`, числа будут одни и те же при каждом запуске:

```csharp
using System;

Random random = new Random(42);
Console.WriteLine(random.Next(1, 7));
Console.WriteLine(random.Next(1, 7));
Console.WriteLine(random.Next(1, 7));
```

Эта программа всегда печатает `5`, `1`, `1`. Каждый вызов Next берёт следующее число цепочки.

В задачах зерно всегда задано — иначе проверка не знала бы, какой вывод правильный. С другим
зерном или другими числами в Next получатся другие броски.
