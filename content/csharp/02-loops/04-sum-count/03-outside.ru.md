# Копилка — снаружи

Копилку объявляют **до** цикла. Если объявить её в теле, будет две беды:

```text
for (int wave = 1; wave <= 4; wave++)
{
    int total = 0;          // каждая итерация начинает с нуля
    total += wave * 5;
}
Console.WriteLine(total);   // ошибка: total здесь не видна
```

- на каждой итерации создаётся новая `total`, равная 0, — сумма не копится;
- после цикла `total` не видна: её область видимости — тело цикла.

И не забудь начальный 0. Если написать `int total;` без значения, а потом `total += …`,
компилятор остановит: в переменную ещё ничего не положили, а к ней уже прибавляют.
