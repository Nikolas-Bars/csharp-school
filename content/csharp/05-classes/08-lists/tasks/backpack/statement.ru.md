Класс `Item` (вещь с именем `name` и весом `weight`) и список `loot` уже есть. Объяви класс
`Inventory` — рюкзак: `private`-поле `items` типа `List<Item>`, поле `maxWeight` и:

- конструктор с параметром `maxWeight` — запоминает его и создаёт пустой список;
- метод `TotalWeight()` — возвращает сумму весов всех вещей в списке;
- метод `Add(Item item)` — если вещь влезает (`TotalWeight()` плюс её вес не больше
  `maxWeight`), кладёт её в список и возвращает `true`, иначе возвращает `false`. Вес `Add`
  узнаёт у `TotalWeight`.

В основном коде создай рюкзак `bag` вместимостью `capacity`. Положи в него по очереди вещи из
`loot`. Для каждой выведи `Взят: Меч` или `Не влезает: Латы`. В конце выведи вес:

```text
Взят: Меч
Взят: Щит
Не влезает: Латы
Вес: 10/10
```

Проверка запустит программу ещё раз с другим `capacity`.
