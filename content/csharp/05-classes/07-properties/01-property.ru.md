# Свойство

Писать для каждого закрытого поля метод вроде `GetHp` долго. В C# для этого есть **свойства** —
члены класса, которые снаружи выглядят как поле, а внутри устроены как пара маленьких методов:
`get` («гет», «получить») отдаёт значение, `set` («сет», «установить») меняет его.

```csharp
using System;

Hero hero = new Hero();
hero.Name = "Мира";
hero.Level = 3;
Console.WriteLine($"{hero.Name}, уровень {hero.Level}");

class Hero
{
    public string Name { get; set; }
    public int Level { get; set; }
}
```

На экране:

```text
Мира, уровень 3
```

- `{ get; set; }` после имени — и есть свойство: его можно и читать, и менять.
- Пользуются им так же, как полем: `hero.Level = 3`, `hero.Level + 1`.
- Свои свойства пиши с заглавной буквы: `Name`, `Level`, `Hp`. У готовых свойств Unity имена
  с маленькой (`transform.position`) — так сложилось исторически.
- Значения по умолчанию те же, что у полей: `0`, `false`, `null`.

Пока такое свойство открыто, как обычное поле. Зачем оно — на следующем экране.
