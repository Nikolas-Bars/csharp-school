# Переменная хранит ссылку

Переменная типа `Hero` хранит не самого героя, а **ссылку** на него — «адрес», по которому
объект можно найти. Так же было с массивами в модуле «Методы». Поэтому присваивание копирует
адрес, а не героя:

```csharp
using System;

Hero hero = new Hero();
hero.hp = 100;

Hero target = hero;
target.hp -= 40;

Console.WriteLine(hero.hp);
Console.WriteLine(target.hp);

class Hero
{
    public int hp;
}
```

На экране:

```text
60
60
```

`hero` и `target` указывают на один и тот же объект: удар по `target` — это удар по `hero`.
Типы, которые хранят ссылку, называют **ссылочными**: все классы такие. А `int`, `double` и
`bool` при присваивании копируются целиком.

Нужен второй герой — нужен второй `new`. Это работает и с методами: если передать объект в
метод, метод получит ссылку и сможет поменять поля того же самого героя.
