# Объект умеет действовать

В классе можно описать не только данные, но и действия — **методы объекта**. Как способности
героя: «показать карточку», «получить урон», «атаковать».

```csharp
using System;

Hero hero = new Hero();
hero.name = "Артур";
hero.hp = 100;
hero.ShowInfo();

class Hero
{
    public string name;
    public int hp;

    public void ShowInfo()
    {
        Console.WriteLine($"{name}: {hp} HP");
    }
}
```

На экране:

```text
Артур: 100 HP
```

- Метод пишут внутри фигурных скобок класса, рядом с полями. Поля и методы вместе называют
  **членами класса** — всё, из чего класс состоит.
- Внутри метода поля доступны просто по имени: `name`, `hp` — без `hero.` впереди.
- `public` перед методом значит то же, что у поля: метод можно вызвать из основного кода.
- Вызывают метод через объект и точку: `hero.ShowInfo()`. Так же, как `bag.Add("меч")` у
  списка: `Add` — метод объекта-списка.

Слова `static` здесь нет — почему, разберём через экран.
