# Где писать класс

Класс пишут в конце файла — после всех команд основного кода. Если поставить класс выше
команд, программа не соберётся:

```text
using System;

class Hero                  // класс выше команд
{
    public int hp;
}

Hero hero = new Hero();     // ошибка CS8803: команды должны идти до классов
```

Свои методы со `static` из модуля «Методы» тоже пишут выше классов. Поэтому порядок в файле
такой:

1. `using`;
2. команды основного кода;
3. методы со `static`;
4. классы.

Классов в одном файле может быть несколько: `Hero`, `Enemy`, `Weapon` — один под другим. В
Unity каждый класс обычно живёт в своём файле, но правила внутри класса те же.
