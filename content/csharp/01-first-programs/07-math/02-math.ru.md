# Набор Math

`Math` — это набор математических методов. Вот ещё два:

```csharp
using System;

Console.WriteLine(Math.Min(7, 12));
Console.WriteLine(Math.Abs(-5));
```

На экране — `7` и `5`.

- `Math.Min(a, b)` — меньшее из двух чисел (а `Math.Max` — большее);
- `Math.Abs(x)` — число без минуса. В математике это называют модулем числа.
