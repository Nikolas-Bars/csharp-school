# И

Иногда одного условия мало. Условия соединяют **логическими операторами**. Первый из них —
`&&`, «и»: всё условие верно, только если верны **обе** части.

```csharp
using System;

int level = 12;
bool hasKey = true;
if (level >= 10 && hasKey)
{
    Console.WriteLine("Можно войти в подземелье.");
}
```

Уровень 12 — не меньше 10, и ключ есть: оба условия верны, сообщение напечатается. Будь уровень
8, не помог бы и ключ.
