# Подставляем значения

Склеивать много кусков неудобно. Есть способ проще — **интерполяция**, то есть подстановка
значений прямо в текст. Перед кавычками ставят `$`, а значения пишут в фигурных скобках `{}`:

```csharp
using System;

string heroName = "Аня";
int hp = 100;
int maxHp = 120;
Console.WriteLine($"{heroName}: {hp} из {maxHp}");
Console.WriteLine($"До полного здоровья: {maxHp - hp}");
```

На экране:

```text
Аня: 100 из 120
До полного здоровья: 20
```

В фигурных скобках можно даже считать — как `maxHp - hp`. Без `$` скобки напечатались бы
как есть: `{heroName}`.
