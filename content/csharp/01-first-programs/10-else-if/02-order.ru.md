# Порядок важен

Поменяем условия местами:

```text
if (hp > 30)       → «Ранен»
else if (hp > 70)  → «Полон сил»
```

При `hp = 90` первое условие уже верно — напечатается «Ранен», а до «Полон сил» дело не
дойдёт никогда.

Поэтому сначала ставят самое строгое условие — то, под которое подходит меньше всего значений:
«больше 70» строже, чем «больше 30». Сначала «больше 70», потом «больше 30», а всё остальное —
в `else`.
