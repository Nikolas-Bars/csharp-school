# else if

Когда вариантов больше двух, между `if` и `else` добавляют `else if` («иначе если»):

```csharp
using System;

int hp = 45;
if (hp > 70)
{
    Console.WriteLine("Полон сил");
}
else if (hp > 30)
{
    Console.WriteLine("Ранен");
}
else
{
    Console.WriteLine("Еле стоит на ногах");
}
```

Напечатается «Ранен». Условия проверяются **сверху вниз**, и срабатывает **первое** верное —
остальные пропускаются. Если не верно ни одно, выполняется `else`. Так что выполняется не
больше одного блока, а если в конце есть `else` — ровно один.
