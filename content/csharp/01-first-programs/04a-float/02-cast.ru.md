# Из дробного — целое: (int)

Урон посчитался дробным — 7.8, а здоровье у героя целое. Положить `double` в `int` просто так
компилятор не даст: дробная часть потерялась бы. Но можно сказать ему «я знаю, превращай».
Для этого перед значением в скобках пишут нужный тип:

```csharp
using System;

double damage = 7.8;
int hit = (int)damage;
Console.WriteLine(hit);
```

Это называют **приведением типа**: `(int)` превращает значение в `int`.

Напечатается `7`, а не 8: `(int)` не округляет, а **отбрасывает** дробную часть. И 7.8, и 7.1
станут 7.
