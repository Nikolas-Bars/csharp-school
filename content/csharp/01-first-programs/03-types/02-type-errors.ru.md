# Тип не перепутать

Тип переменной выбирают один раз, и класть в неё можно только значения этого типа. Так
компилятор ловит ошибки ещё до запуска программы:

```text
int hp = "сто";     // ошибка: "сто" — это string, а не int
int speed = 2.5;    // ошибка: у дробного числа потерялась бы часть .5
```

А целое число в `double` положить можно — ничего не теряется:

```csharp
using System;

double damage = 10;
Console.WriteLine(damage);
```

Напечатается `10`.

Строка `"5"` и число `5` выглядят на экране одинаково, но это разные вещи: с числом можно
считать, а строка — просто текст из символа 5.
