# const и var

Бывают значения, которые в игре не меняются: максимум здоровья, число уровней. Их объявляют
со словом `const` перед типом — получается **константа** (от английского constant —
«постоянный»):

```csharp
using System;

const int maxHp = 100;
var gold = 50;
Console.WriteLine(maxHp);
Console.WriteLine(gold);
```

Значение константы задают сразу и больше не меняют: если ниже написать `maxHp = 120;`,
компилятор выдаст ошибку.

`var` ты встретишь в чужом коде и в примерах для Unity. Это не новый тип: вместо типа пишут
`var`, а компилятор сам смотрит на значение справа и выбирает тип — здесь `int`. Тип у `gold`
всё равно один и навсегда. В курсе мы пишем тип явно: так сразу видно, что лежит в коробке.
