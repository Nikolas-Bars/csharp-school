Создай четыре переменные с подходящими типами:

- `heroName` — имя героя «Аня»;
- `level` — уровень 5;
- `speed` — скорость 1.5;
- `hasSword` — есть ли меч: да.

Выведи их по порядку:

```text
Аня
5
1.5
True
```

Программа должна работать и с другим героем — проверка запустит её ещё раз с другими
`heroName` и `level`.
