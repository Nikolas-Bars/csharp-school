# Что такое переменная

**Переменная** — это коробка с именем, в которой программа хранит значение. Например, здоровье
героя:

```csharp
using System;

int hp = 100;
Console.WriteLine(hp);
```

Разберём строку `int hp = 100;`:

- `int` — **тип**: что можно положить в коробку. `int` (от английского integer — «целое») —
  целое число: 0, 7, -15, 100.
- `hp` — имя переменной. По нему мы потом достаём значение. hp — сокращение от английского
  health points, «очки здоровья».
- `=` — **присваивание**: «положи значение справа в переменную слева». Это не «равно» из
  математики, а команда.
- `100` — само значение.

`Console.WriteLine(hp)` печатает **значение** переменной — `100`. Обрати внимание: имя
написано без кавычек. `Console.WriteLine("hp")` напечатал бы просто буквы hp.
