Перед битвой с боссом проверь героя. У героя `level = 12`, `hp = 100`, `maxHp = 100`, у босса
`bossLevel = 10`. Выведи три строки с ответами-сравнениями:

```text
Уровень выше босса: True
Здоровье полное: True
Уровни равны: False
```

Ответы True и False не пиши сам текстом — пусть их посчитают сравнения.

Программа должна работать и с другим героем — проверка запустит её ещё раз с другими `level` и `hp`.
