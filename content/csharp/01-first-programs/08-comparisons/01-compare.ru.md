# Больше, меньше, равно

Числа можно сравнивать. Результат сравнения — `bool`: `true`, если верно, и `false`, если нет.

- `>` больше, `<` меньше;
- `>=` больше или равно, `<=` меньше или равно;
- `==` равно — **два** знака равенства;
- `!=` не равно.

```csharp
using System;

int hp = 30;
Console.WriteLine(hp > 0);
Console.WriteLine(hp == 100);
Console.WriteLine(hp != 100);
```

На экране — `True`, `False`, `True`.

Не путай: один знак `=` кладёт значение в переменную, два `==` — сравнивают.
