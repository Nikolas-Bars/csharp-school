# switch по строке

В `switch` можно проверять и строку — например, команду из игрового меню:

```csharp
using System;

string command = "карта";
switch (command)
{
    case "инвентарь":
        Console.WriteLine("Открыт инвентарь");
        break;
    case "карта":
        Console.WriteLine("Открыта карта");
        break;
    default:
        Console.WriteLine("Неизвестная команда");
        break;
}
```

Строки сравниваются буква в букву, как в `==`: `"Карта"` с заглавной не совпадёт с
`case "карта"`.

Когда что удобнее:

- `switch` — когда одна переменная сравнивается с точными значениями: этаж 1, 2, 3; команда
  «карта» или «инвентарь»; состояние врага.
- `else if` — когда в условиях сравнения «больше-меньше»: `hp > 70`, `score >= 500`. Для
  `switch` здесь пришлось бы перечислять каждое число по отдельности.
