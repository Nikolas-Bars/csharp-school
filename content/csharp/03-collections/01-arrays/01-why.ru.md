# Зачем нужен массив

В таблице рекордов пять игроков. Можно завести пять переменных: `score1`, `score2`, `score3`…
А если игроков сто? Сто переменных никто писать не будет.

Для этого есть **массив** — одна переменная, в которой лежит сразу много значений одного типа,
по порядку. Как ряд ячеек в инвентаре: ячейки идут одна за другой, и в каждой что-то лежит.

Каждое значение в массиве называют **элементом**.

```csharp
using System;

int[] scores = { 120, 95, 80 };
Console.WriteLine(scores[0]);
```

- `int[]` — тип «массив целых чисел»: квадратные скобки `[]` после типа означают массив.
- В фигурных скобках через запятую — элементы: 120, 95 и 80.
- `scores[0]` — взять из массива один элемент.

Напечатается `120` — первый элемент. Почему у первого `[0]`, а не `[1]`, — на следующем экране.
