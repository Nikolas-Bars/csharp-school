# Номер элемента — индекс

Номер элемента в массиве называют **индексом**. Его пишут в квадратных скобках после имени
массива: `scores[1]`.

Главное правило: индексы начинаются **с нуля**. Первый элемент — `scores[0]`, второй —
`scores[1]`, третий — `scores[2]`.

```csharp
using System;

int[] scores = { 120, 95, 80 };
Console.WriteLine(scores[0]);
Console.WriteLine(scores[1]);
Console.WriteLine(scores[2]);
Console.WriteLine($"Первые двое вместе: {scores[0] + scores[1]}");
```

На экране:

```text
120
95
80
Первые двое вместе: 215
```

Индекс — это не «какой по счёту», а «сколько шагов от начала». До первого элемента — ноль
шагов, до третьего — два.

Элемент массива работает как обычная переменная: его можно печатать, складывать, сравнивать.

В квадратных скобках может стоять не только число, но и переменная или вычисление. Если
`int n = 2;`, то `scores[n]` — это `scores[2]`, а `scores[n - 1]` — это `scores[1]`.
