# Есть ли в массиве?

Чтобы узнать, есть ли нужный элемент, заводят **флаг** — переменную `bool`. Как флажок: сначала
опущен (`false`), а когда элемент нашёлся — поднят (`true`):

```csharp
using System;

string[] items = { "факел", "ключ", "хлеб" };
bool hasKey = false;
foreach (string item in items)
{
    if (item == "ключ")
    {
        hasKey = true;
    }
}

if (hasKey)
{
    Console.WriteLine("Можно открыть дверь.");
}
else
{
    Console.WriteLine("Нужен ключ.");
}
```

Напечатается «Можно открыть дверь.».

Ответ печатают **после** цикла: сказать «нет» можно, только когда просмотрены все элементы.
Если нужный нашёлся раньше, можно не смотреть дальше — выйти из цикла через `break`, как в модуле «Циклы».
