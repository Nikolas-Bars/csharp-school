# Заглавные и строчные

Напомним: **верхний регистр** — заглавные буквы (A, Б, HELLO), **нижний регистр** — строчные
(a, б, hello). У строки есть методы, которые меняют регистр:

```csharp
using System;

string spell = "Огненный шар";
Console.WriteLine(spell.ToUpper());
Console.WriteLine(spell.ToLower());
Console.WriteLine(spell);
```

На экране:

```text
ОГНЕННЫЙ ШАР
огненный шар
Огненный шар
```

- `ToUpper()` («в верхний») — та же строка заглавными буквами, `ToLower()` («в нижний») —
  строчными. Цифры, пробелы и знаки не меняются, порядок символов тот же.
- Это методы, поэтому круглые скобки обязательны: `spell.ToUpper()`. У `Length` скобок нет —
  это не метод.
- Сама `spell` не изменилась. Строку нельзя изменить — метод отдаёт **новую** строку. Чтобы её
  сохранить, кладут ответ в переменную: `spell = spell.ToUpper();`. А команда
  `spell.ToUpper();` сама по себе ничего не меняет: новая строка тут же теряется.
