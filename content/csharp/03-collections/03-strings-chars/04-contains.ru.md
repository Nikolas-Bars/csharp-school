# Есть ли в строке?

Метод `Contains` («содержит») отвечает `true` или `false`: есть ли в строке такой кусок текста.

```csharp
using System;

string item = "Старый меч";
Console.WriteLine(item.Contains("меч"));
Console.WriteLine(item.Contains("Меч"));
```

На экране — `True` и `False`. `Contains`, как и `==`, различает регистр: «меч» и «Меч» для него
разные.

А игрок может написать «да», «Да» или «ДА». Чтобы сравнить **без учёта регистра**, обе стороны
приводят к одному регистру — например, к строчным:

```csharp
using System;

string answer = "ДА";
if (answer.ToLower() == "да")
{
    Console.WriteLine("Герой соглашается.");
}
```

Напечатается «Герой соглашается.»: `answer.ToLower()` — это `"да"`.

Методы можно ставить друг за другом: `item.ToLower().Contains("меч")`. Сначала `ToLower`
отдаёт строку строчными буквами, а потом у неё спрашивают `Contains`. Так найдётся и «Меч», и
«МЕЧ».
