# Записать в элемент

В элемент массива можно не только смотреть, но и класть новое значение — так же, как в обычную
переменную:

```csharp
using System;

int[] partyHp = { 100, 45, 80 };
partyHp[1] = 60;
partyHp[2] -= 30;
Console.WriteLine(partyHp[1]);
Console.WriteLine(partyHp[2]);
```

На экране:

```text
60
50
```

`partyHp[1] = 60;` заменяет второй элемент: было 45, стало 60. Остальные элементы не меняются.

Работают и короткие записи из первого модуля: `+=`, `-=`, `*=`, `++`, `--`.
