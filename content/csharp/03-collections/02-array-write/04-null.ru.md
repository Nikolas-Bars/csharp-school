# null — «ничего»

Массив строк тоже можно создать через `new`. Но в его ячейках нет ни слов, ни даже пустой
строки `""` — там `null` («нулл»). Это особое значение: «здесь ещё ничего нет».

```csharp
using System;

string[] party = new string[3];
party[0] = "Аня";
Console.WriteLine(party[0]);
Console.WriteLine(party[1] == null);
```

На экране:

```text
Аня
True
```

Напечатать такую ячейку можно — выйдет пустая строка. А вот попросить у неё что-нибудь нельзя.
Например, у каждой строки можно узнать длину — сколько в ней символов (об этом — в уроке
«Строки и символы»). Но у `null` нет ни символов, ни самой строки:

```text
Console.WriteLine(party[1].Length);   // программа остановится: NullReferenceException
```

Компилятор такую программу пропустит, а при запуске она остановится с ошибкой
**NullReferenceException** — «обращение к ничему».

Поэтому массив строк, созданный через `new`, сначала заполняют, а потом пользуются.
