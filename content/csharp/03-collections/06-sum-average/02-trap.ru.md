# Ловушка среднего

Среднее — это сумма, делённая на количество. Средний урон по четырём ударам:

```csharp
using System;

int[] damage = { 12, 15, 10, 14 };
int total = 0;
foreach (int d in damage)
{
    total += d;
}
double average = total / damage.Length;
Console.WriteLine(average);
```

На экране:

```text
12
```

Сумма 51, а 51 / 4 — это 12.75. Откуда 12? Это ловушка из первого модуля: `total` и `Length` —
целые, поэтому деление **целое**, дробная часть отбрасывается.

То, что результат кладут в `double`, не помогает: деление уже выполнено, и дробная часть
потерялась раньше.
