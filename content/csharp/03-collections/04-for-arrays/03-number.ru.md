# Номер для человека

Людям привычнее считать с единицы: «1 место», а не «0 место». Тогда печатают `i + 1`, а индекс
не трогают:

```csharp
using System;

string[] heroes = { "Аня", "Борис", "Вика" };
for (int i = 0; i < heroes.Length; i++)
{
    Console.WriteLine($"{i + 1}. {heroes[i]}");
}
```

На экране:

```text
1. Аня
2. Борис
3. Вика
```

`i` — индекс, с ним берём элемент `heroes[i]`. `i + 1` — только для текста на экране.

Не путай `i` и `heroes[i]`: `i` — номер ячейки, а `heroes[i]` — то, что в ней лежит.
