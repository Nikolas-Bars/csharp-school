# Перебор массива

Три элемента можно вывести тремя командами. А если их сто? Тут помогает цикл `for` из прошлого
модуля.

Пройти по всем элементам по очереди, от первого до последнего, называется **перебором**.
Счётчик цикла `i` как раз и будет индексом:

```csharp
using System;

int[] scores = { 120, 95, 80, 60 };
for (int i = 0; i < scores.Length; i++)
{
    Console.WriteLine(scores[i]);
}
```

На экране:

```text
120
95
80
60
```

- `i` начинается с 0 — с первого индекса.
- Условие `i < scores.Length` — «пока индекс меньше длины». Последний раз цикл выполнится,
  когда `i` равно 3, — это последний индекс.
- Добавишь в массив пятый элемент — цикл пройдёт и по нему: длину он берёт из `Length`.
