# Две частые ошибки

```text
for (int i = 1; i < scores.Length; i++)    // начали с 1 — пропущен scores[0]
for (int i = 0; i <= scores.Length; i++)   // <= — i дойдёт до Length, такого индекса нет
```

Первая ошибка тихая: программа работает, но первый элемент пропускает. Вторая останавливает
программу с IndexOutOfRangeException.

Запомни шаблон: `for (int i = 0; i < a.Length; i++)` — от нуля и **строго меньше** длины.
