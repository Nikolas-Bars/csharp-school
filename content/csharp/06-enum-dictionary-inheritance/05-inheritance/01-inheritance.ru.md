# Наследование: общее — в одном месте

У орка и гоблина много общего: имя, здоровье, получение урона. Если написать два отдельных
класса, одинаковый код придётся повторить дважды — и исправлять ошибку тоже в двух местах.

Общее выносят в один класс, а виды врагов строят на нём:

```csharp
using System;

Orc orc = new Orc();
orc.name = "Грох";
orc.hp = 60;
orc.TakeDamage(15);
Console.WriteLine($"{orc.name}: {orc.hp} HP");

class Enemy
{
    public string name;
    public int hp;

    public void TakeDamage(int damage)
    {
        hp = Math.Max(hp - damage, 0);
    }
}

class Orc : Enemy
{
}
```

На экране:

```text
Грох: 45 HP
```

- `class Orc : Enemy` — орк **наследует** врага. Двоеточие после имени читается «построен на».
  У орка уже есть поля `name` и `hp` и метод `TakeDamage`, хотя в фигурных скобках `Orc` пусто.
- `Enemy` — **базовый класс**, `Orc` — **наследник**. Наследников у одного класса может быть
  сколько угодно: `Orc`, `Goblin`, `Troll`.

Это и называют **наследованием**: наследник получает всё, что есть у базового класса.
