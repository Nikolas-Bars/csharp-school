# Двоеточие в скрипте Unity

Помнишь скрипт Unity из модуля «Классы и объекты»?

```text
public class Player : MonoBehaviour
{
    void Update()
    {
    }
}
```

Теперь двоеточие понятно: класс `Player` — наследник `MonoBehaviour`. `MonoBehaviour` — базовый
класс, который написали разработчики Unity. От него твой скрипт получает готовое: `transform`
(положение объекта в мире), `gameObject` (сам объект в игре), метод `GetComponent` и многое
другое.

Поэтому Unity и умеет работать с любым твоим скриптом: для неё каждый скрипт — это
`MonoBehaviour`. А `Start` и `Update` Unity находит в скрипте по имени, поэтому их пишут просто:
`void Update()`.

Всё, что ты узнаешь в этом модуле о наследовании, в Unity работает так же.
