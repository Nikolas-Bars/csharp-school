# Перечисление — свой набор значений

У врага в игре есть **состояние**: он стоит на месте, идёт или атакует. От состояния зависит, что
враг делает прямо сейчас. Как его хранить?

Можно строкой: `string state = "walk";`. Но в строке легко ошибиться — `"wlak"` или `"Walk"`, — и
компилятор промолчит: для него это просто другой текст. Можно числом: `int state = 1;`. Но через
неделю не вспомнишь, что значит 1, а что 2.

Для этого в C# есть **перечисление** — по-английски enum («инам», от enumeration — «перечисление»).
Это свой тип с несколькими именованными значениями:

```csharp
using System;

State state = State.Walk;
Console.WriteLine(state);

enum State { Idle, Walk, Attack }
```

На экране:

```text
Walk
```

- `enum State` — объявление перечисления с именем `State` («стейт», «состояние»).
- В фигурных скобках через запятую — все его значения: `Idle` («айдл», «покой»), `Walk`
  («ходьба»), `Attack` («атака»). Других значений у типа `State` нет.
- Значение пишут через точку: `State.Walk`. Ошибёшься в имени — `State.Wlak` — и компилятор сразу
  скажет, что такого значения нет.
