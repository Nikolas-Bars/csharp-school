# Забытый override

Если у наследника написать метод с тем же именем, но без `override`, программа соберётся —
компилятор только предупредит (CS0114): метод наследника **прячет** метод базового класса. И
работает он тогда, только если переменная — типа наследника:

```text
Orc orc = new Orc("Грох");
orc.Attack();                // Грох бьёт дубиной: 12 урона

Enemy enemy = orc;
enemy.Attack();              // Грох кусает: 2 урона — версия Enemy!

class Orc : Enemy
{
    public void Attack()     // забыт override: предупреждение CS0114
    {
        Console.WriteLine($"{name} бьёт дубиной: 12 урона");
    }
}
```

В списке `List<Enemy>` такой орк будет атаковать по-старому. Поэтому предупреждение CS0114 — повод
проверить: скорее всего, забыт `override`.

Ещё две частые ошибки — их компилятор не пропустит:

- `override` без `virtual` в базовом классе — ошибка CS0506: заменять можно только то, что
  разрешено словом `virtual`.
- `override void Attack()` без `public` — ошибка CS0507: доступ у заменённого метода должен быть
  тот же, что у базового.
