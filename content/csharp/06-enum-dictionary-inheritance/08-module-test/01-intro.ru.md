# Контрольная: зоопарк монстров

Пора собрать всё вместе. В этом модуле были:

- **перечисление** `enum` — свой тип с именованными значениями, например состояния врага `Idle`,
  `Walk`, `Attack`, и `switch` по нему: `case State.Attack:`;
- **словарь** `Dictionary<string, int>` — значение по ключу: `Add`, `[ключ]`, `ContainsKey`,
  `TryGetValue`, `Remove` и перебор пар через `pair.Key` и `pair.Value`;
- **наследование** `class Orc : Enemy` — наследник получает поля и методы базового класса,
  `protected` открывает поле наследникам, а `: base(…)` вызывает конструктор базового класса;
- `virtual` и `override` — своя версия метода у каждого наследника, `base.Act()` — версия базового
  класса. В `List<Enemy>` у каждого объекта работает его версия.

Впереди две задачи: монстры, которые ведут себя по своему состоянию, и добыча с поверженных
врагов. Потом — вопросы по всему модулю.
