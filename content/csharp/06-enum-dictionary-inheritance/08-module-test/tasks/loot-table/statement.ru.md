Герой победил врагов из массива `defeated`, и они уже собраны в список `enemies`. С каждого врага
падает добыча — её возвращает метод `Loot()`: обычный враг оставляет `кость`.

1. Сделай так, чтобы у наследников была своя добыча: `Slime` (слизень) оставляет `слизь`, `Dragon`
   (дракон) — `чешуя`.
2. Пройди по списку `enemies` и собери добычу в словарь `loot` типа `Dictionary<string, int>`:
   предмет → сколько штук. Предмет узнавай у каждого врага через `Loot()`.
3. Выведи словарь циклом по парам — через `pair.Key` и `pair.Value`:

```text
слизь: 2
кость: 1
чешуя: 1
```

Проверка запустит программу ещё раз с другим массивом `defeated`.
