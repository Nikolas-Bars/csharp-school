# Словарь: значение по ключу

В инвентаре у героя 3 зелья, 20 стрел и 1 ключ. Можно завести два списка — названия и
количества — и следить, чтобы номера совпадали. Но удобнее спрашивать прямо: «сколько у меня
стрел?»

Для этого есть **словарь** — `Dictionary` («дикшенери»). Он хранит пары «ключ → значение»: по
ключу (названию предмета) находится значение (количество). Как в настоящем словаре: по слову
находишь его объяснение.

```csharp
using System;
using System.Collections.Generic;

Dictionary<string, int> items = new Dictionary<string, int>();
items.Add("зелье", 3);
items.Add("стрела", 20);
items.Add("ключ", 1);

Console.WriteLine(items["стрела"]);
Console.WriteLine($"Видов предметов: {items.Count}");
```

На экране:

```text
20
Видов предметов: 3
```

- `Dictionary<string, int>` — словарь, где ключ — `string`, а значение — `int`. Как у `List<int>`,
  типы пишут в угловых скобках: сначала тип ключа, потом тип значения. Живёт словарь там же, где
  `List`, — нужен `using System.Collections.Generic;`.
- `Add(ключ, значение)` добавляет пару.
- `items["стрела"]` — значение по ключу. Квадратные скобки — как у массива, только вместо номера
  — ключ.
- `Count` — сколько в словаре пар.

Каждый ключ в словаре один: двух «стрел» быть не может. А значения могут повторяться — зелий и
ключей может быть поровну.
