# Конструктор базового класса: base

У врага есть конструктор: без имени и здоровья врага не создать. Наследник обязан его вызвать:
внутри орка есть «часть врага», и её кто-то должен заполнить. Для этого после скобок конструктора
наследника пишут `: base(…)`:

```csharp
using System;

Orc orc = new Orc("Грох");
orc.Info();

class Enemy
{
    public string name;
    public int hp;

    public Enemy(string name, int hp)
    {
        this.name = name;
        this.hp = hp;
    }

    public void Info()
    {
        Console.WriteLine($"{name}: {hp} HP");
    }
}

class Orc : Enemy
{
    public Orc(string name) : base(name, 60)
    {
    }
}
```

На экране:

```text
Грох: 60 HP
```

- `base` («бейс», «основа») — базовый класс. `: base(name, 60)` вызывает конструктор `Enemy` с
  этими значениями: имя пришло в конструктор орка, а здоровье у всех орков 60.
- Конструктор базового класса выполняется **первым**, потом — тело конструктора наследника.

Если `: base(…)` не написать, C# попробует вызвать у `Enemy` конструктор без параметров. А его нет —
ошибка CS7036: конструктору `Enemy` не хватает значения для `name`.
