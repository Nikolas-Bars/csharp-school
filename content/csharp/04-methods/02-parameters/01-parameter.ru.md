# Параметр

Лечение бывает слабым и сильным. Чтобы не писать отдельный метод под каждое число, значение
передают методу при вызове. Для этого в скобках объявления пишут **параметр** — переменную
метода, которая получает значение снаружи:

```csharp
using System;

Heal(20);
Heal(50);

static void Heal(int amount)
{
    Console.WriteLine($"Герой лечится на {amount} HP");
}
```

На экране:

```text
Герой лечится на 20 HP
Герой лечится на 50 HP
```

`int amount` — параметр: тип и имя, как у обычной переменной. При вызове `Heal(20)` в
`amount` кладётся 20, при `Heal(50)` — 50.

Само значение в скобках вызова — **аргумент**. Это слово уже было в уроке про `Math`:
`Math.Max(7, 12)` получает два аргумента. Параметр — «место» в объявлении, аргумент — то,
что туда кладут при вызове.
