# Что можно передать

Аргументом может быть число, переменная или даже **выражение** — вычисление вроде
`potion * 2`. Главное, чтобы получилось значение нужного типа:

```csharp
using System;

int potion = 15;
Heal(potion);
Heal(potion * 2);

static void Heal(int amount)
{
    Console.WriteLine($"Герой лечится на {amount} HP");
}
```

На экране — «Герой лечится на 15 HP» и «Герой лечится на 30 HP». Сначала считается
`potion * 2`, и уже готовое число 30 попадает в `amount`.

Компилятор следит за аргументами:

- `Heal("20")` — ошибка: в скобках строка, а параметр — `int`;
- `Heal()` — ошибка: параметр есть, а значения для него не передали.
