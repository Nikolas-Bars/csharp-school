На арену выходят волны врагов. Объяви метод `AnnounceWave` с параметром `wave` типа `int`,
который печатает, например:

```text
Волна 1: враги идут!
```

Сколько всего волн, хранит переменная `waves = 4`. В основном коде вызови `AnnounceWave` в цикле
`for` для волн с 1-й по последнюю. На экране:

```text
Волна 1: враги идут!
Волна 2: враги идут!
Волна 3: враги идут!
Волна 4: враги идут!
```

Программа должна работать и при другом числе волн: проверка запустит её ещё раз с другим
значением `waves`.
