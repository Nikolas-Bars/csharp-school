# Несколько параметров

Параметров может быть несколько. Их перечисляют через запятую, и у каждого свой тип:

```csharp
using System;

Hit("Гоблин", 12);
Hit("Орк", 25);

static void Hit(string target, int damage)
{
    Console.WriteLine($"{target} получает {damage} урона");
}
```

На экране:

```text
Гоблин получает 12 урона
Орк получает 25 урона
```

Аргументы при вызове тоже идут через запятую. Типы у параметров могут быть разными: здесь
`target` — строка, а `damage` — целое число.
