# Перегрузка в нашей программе

Свои методы в нашем файле перегрузить не получится. Помнишь, они называются локальными
функциями? У локальных функций имена не должны повторяться:

```text
static int Add(int a, int b) { … }
static double Add(double a, double b) { … }   // ошибка CS0128: имя Add уже занято
```

Поэтому здесь каждому методу — своё имя: например, `HealPoints` для лечения на число очков и
`HealPercent` для лечения на процент. Так даже понятнее.

В классах — а в Unity методы живут именно там — свои методы перегружать можно. И готовых
перегрузок в Unity много. Например, метод `Random.Range` выдаёт случайное число и есть в двух
вариантах — для целых и для дробных чисел. Это `Random` из Unity, не тот `Random`, что был в
модуле «Циклы»: у Unity свой набор с таким же именем.
