# Что ждёт в Unity

В Unity скрипт — это класс, а в нём методы. Два из них встретятся тебе в первый же день:

```text
using UnityEngine;

public class Hero : MonoBehaviour
{
    void Start()
    {
        // печать в Unity — о ней на следующем экране
        Debug.Log("Герой появился!");
    }

    void Update()
    {
        // выполняется каждый кадр
    }
}
```

- `using UnityEngine;` подключает набор Unity — так же, как `using System;` подключает
  `Console` и `Math`.
- `public class Hero : MonoBehaviour { … }` — обёртка скрипта: класс `Hero`, а
  `: MonoBehaviour` помечает, что это скрипт Unity. О классах — в следующем модуле.
- `Start` выполняется один раз — перед первым кадром, когда скрипт включён. Скрипт в Unity
  можно включать и выключать галочкой в редакторе.
- **Кадр** — одна картинка на экране. Игра рисует их десятки раз в секунду, и перед каждой
  вызывается `Update`.

Эти методы не нужно вызывать из своего кода — их вызывает Unity в нужный момент. А внутри
пишешь то же, что и здесь: переменные, условия, циклы и вызовы своих методов вроде `Attack()`
или `IsAlive(hp)`. Объявление, параметры, `return`, имена в PascalCase — всё это там работает
так же.
