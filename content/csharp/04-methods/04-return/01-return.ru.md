# Метод отвечает

`Math.Max` ничего не печатает, а **возвращает** результат: считает и отдаёт ответ туда, откуда
его вызвали. Свой метод тоже так умеет:

```csharp
using System;

int damage = CalculateDamage(25, 10);
Console.WriteLine(damage);

static int CalculateDamage(int attack, int armor)
{
    int result = attack - armor;
    return result;
}
```

Напечатается `15`. Что изменилось:

- вместо `void` стоит `int` — это **тип возвращаемого значения** (коротко — тип возврата):
  метод отвечает целым числом;
- `return` («ретёрн», по-английски «вернуть») — команда «отдай это значение и выйди из метода».

Ответ метода называют **возвращаемым значением**. Вызов `CalculateDamage(25, 10)` сам
становится числом 15 — его и кладут в `damage`.
