# Где видна переменная

Это уже встречалось в циклах (урок «Шаг и обратный отсчёт», экран «Область видимости»):
счётчик `for` не виден после цикла, а переменная из фигурных скобок — снаружи блока. Это **область видимости** — часть программы, где имя видно. У методов то же
правило: переменная, объявленная внутри метода, существует только в нём.

```text
using System;

Loot();
Console.WriteLine(gold);    // ошибка CS0103: имя gold не найдено

static void Loot()
{
    int gold = 50;
    Console.WriteLine(gold);
}
```

`gold` видна от объявления до конца тела `Loot`. Метод закончил работу — и его переменных
больше нет.

Это даже удобно: в разных методах переменные можно называть одинаково, и они не мешают друг
другу. А если значение нужно снаружи — метод отдаёт его через `return`.
