# Что значит static

Работает и в обратную сторону: метод со словом `static` не видит переменных основного кода.

```text
using System;

int hp = 100;
Hit();

static void Hit()
{
    hp -= 10;    // ошибка CS8421: static-метод не может обращаться к hp
}
```

В этом и смысл `static` в нашей программе: метод **самостоятельный**. Всё, что ему нужно, он
получает через параметры, а результат отдаёт через `return`. Такой метод нельзя случайно
сломать, поменяв что-то снаружи, и его легко перенести в другую программу.

Без `static` метод в нашем файле видел бы переменные основного кода. Мы так не делаем и всегда
пишем `static`.

В Unity у слова `static` будет другой, более широкий смысл — разберём его, когда дойдём до
классов. А методы `Start` и `Update` там пишут без `static`.
