# Короткий выбор: ?:

Когда из двух значений нужно выбрать одно, вместо `if` и `else` можно написать **тернарный
оператор** `?:` («тернарный» — из трёх частей):

```csharp
using System;

Console.WriteLine(GetStatus(30));
Console.WriteLine(GetStatus(0));

static string GetStatus(int hp)
{
    return hp > 0 ? "В бою" : "Повержен";
}
```

На экране:

```text
В бою
Повержен
```

Читается так: «условие `?` значение, если да `:` значение, если нет». Если `hp > 0`, получится
`"В бою"`, иначе — `"Повержен"`. Это то же самое, что `if (hp > 0) { return "В бою"; }` и
`return "Повержен";` — только в одну строку.

- `?:` даёт значение, поэтому его ставят туда, где нужно значение: в `return`, в переменную
  `string status = hp > 0 ? "В бою" : "Повержен";`, в интерполяцию. В интерполяции его берут в
  круглые скобки: `$"Дверь {(hasKey ? "открыта" : "заперта")}"`.
- Оба значения — одного типа: `hp > 0 ? "жив" : 0` не скомпилируется.
- Вариантов два — `?:`. Три и больше — `if`: цепочку из `?:` трудно читать.
