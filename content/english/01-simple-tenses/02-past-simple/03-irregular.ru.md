# Неправильные глаголы

**Неправильные глаголы** — у них своя форма прошедшего времени, без -ed. По правилу её не
вывести, её запоминают. Их меньше, чем правильных, но это самые частые слова:

| Глагол | Прошедшее | Перевод |
|---|---|---|
| be | **was / were** | быть |
| go | **went** | идти, ехать |
| have | **had** | иметь |
| do | **did** | делать |
| see | **saw** | видеть |
| come | **came** | приходить |
| get | **got** | получать |
| make | **made** | делать, готовить |
| take | **took** | брать |
| say | **said** | говорить, сказать |
| buy | **bought** | покупать |
| eat | **ate** | есть |
| drink | **drank** | пить |
| write | **wrote** | писать |

У be две формы: **was** — с I, he, she, it; **were** — с you, we, they.

```mistake
He goed to school.
He went to school.
go — неправильный глагол: -ed к нему не добавляют, у него своя форма — went.
```
