# Неправильные глаголы: три формы

У **неправильных глаголов** третья форма своя, её запоминают — как вторую в Past Simple. Учи
сразу тройками: go — went — gone.

| Глагол | Вторая форма | Третья форма | Перевод |
|---|---|---|---|
| be | was / were | **been** | быть |
| go | went | **gone** | идти, ехать |
| do | did | **done** | делать |
| have | had | **had** | иметь |
| see | saw | **seen** | видеть |
| eat | ate | **eaten** | есть |
| write | wrote | **written** | писать |
| take | took | **taken** | брать |
| give | gave | **given** | давать |
| break | broke | **broken** | ломать, разбить |
| forget | forgot | **forgotten** | забывать |
| know | knew | **known** | знать |
| speak | spoke | **spoken** | говорить |
| drive | drove | **driven** | водить машину |
| fly | flew | **flown** | летать |
| swim | swam | **swum** | плавать |
| begin | began | **begun** | начинать |
| come | came | **come** | приходить |
| lose | lost | **lost** | терять |
| find | found | **found** | находить |
| make | made | **made** | делать, готовить |
| buy | bought | **bought** | покупать |
| meet | met | **met** | встречать, знакомиться |
| get | got | **gotten** | получать |
| leave | left | **left** | уходить, уезжать |
| ride | rode | **ridden** | ехать верхом, кататься |
| win | won | **won** | выигрывать |
| read | read | **read** | читать |

- У многих вторая и третья формы совпадают: lost — lost, bought — bought, made — made.
- У come третья форма — как начальная: come — came — **come**.
- В Америке третья форма get — **gotten**: I've gotten a new bike.
- read во всех трёх формах пишется одинаково, но звучит по-разному: «рид» — «ред» — «ред».

```mistake
He has went home.
He has gone home.
После has — третья форма. У go это gone, а went — вторая, для Past Simple.
```
