# Как пишется -ing

Сначала два слова. **Гласные** буквы — a, e, i, o, u: ими можно тянуть звук голосом. Все остальные —
**согласные**: b, d, m, n, t и так далее.

Чаще всего -ing просто добавляется: work → working, play → playing, read → reading,
study → studying, go → going.

Три особых случая:

- **e на конце не читается** — её убирают: make → making, write → writing, come → coming.
  Но see → seeing: здесь e читается.
- **Короткий глагол** (один слог — произносится за один раз: run, sit, swim) оканчивается на
  согласную + гласную + согласную — последнюю согласную **удваивают**: run → running,
  sit → sitting, swim → swimming, get → getting. w, x и y не удваивают: play → playing, fix → fixing.
- **ie на конце** меняется на **y**: lie → lying (лежать), die → dying, tie → tying.

```example
The kids are swimming in the lake.
Дети плавают в озере.

The dog is lying on the sofa.
Собака лежит на диване.
```

```mistake
She is writting a message.
She is writing a message.
В write на конце немая e — её просто убирают. Удваивать t не нужно.

We are runing to school.
We are running to school.
run — короткий: согласная + гласная + согласная. Последнюю n удваивают.
```
