# Лучший результат

Как найти самый большой элемент? Так же, как ищет человек: запомнить первый результат и идти
дальше. Попалось число больше — запомнить его вместо старого.

```csharp
using System;

int[] scores = { 120, 340, 95, 210 };
int best = scores[0];
foreach (int s in scores)
{
    if (s > best)
    {
        best = s;
    }
}
Console.WriteLine($"Рекорд: {best}");
```

На экране:

```text
Рекорд: 340
```

Самое большое значение называют **максимумом**, самое маленькое — **минимумом**.

Вместо `if` можно написать `best = Math.Max(best, s);` — из двух чисел останется большее.
