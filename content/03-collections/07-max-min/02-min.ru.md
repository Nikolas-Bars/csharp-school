# Самый слабый

Минимум ищут так же, только знак сравнения наоборот: `if (hp < weakest)`.

Почему начинают с первого элемента, а не с числа 0? Попробуй найти самого слабого врага так:

```text
int weakest = 0;   // ошибка: ни один враг не слабее нуля
```

Ни одно здоровье не окажется меньше 0, и ответом станет 0 — а врага с таким здоровьем в массиве
нет. Первый элемент — точно настоящее значение из массива, с ним сравнивать честно.

С максимумом та же беда, если числа отрицательные. В массиве `{ -5, -3, -8 }` максимум — это -3,
а если начать с 0, ответом станет 0: ни один элемент не больше нуля.
