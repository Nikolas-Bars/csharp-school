# Массив строк

Массив хранит значения любого типа, не только `int`. Например, инвентарь — это массив строк:

```csharp
using System;

string[] items = { "меч", "щит", "зелье" };
items[2] = "пустая бутылка";
Console.WriteLine($"В руке: {items[0]}");
Console.WriteLine($"В сумке: {items[2]}");
```

На экране:

```text
В руке: меч
В сумке: пустая бутылка
```

Бывают и `double[]`, и `bool[]`. Правило одно: все элементы массива — одного типа. Положить
число в массив строк нельзя.
