# Массив нужного размера

Бывает, что элементы заранее неизвестны: патроны появятся только во время игры. Тогда создают
массив нужной **длины** (сколько в нём элементов), пока заполненный нулями:

```csharp
using System;

int[] ammo = new int[3];
ammo[0] = 30;
Console.WriteLine(ammo[0]);
Console.WriteLine(ammo[1]);
```

На экране:

```text
30
0
```

- `new int[3]` — новый массив из трёх целых чисел. `new` значит «создай».
- Все элементы такого массива сначала равны нулю: `ammo[1]` никто не трогал, и там 0.
- У `bool[]` ячейки сначала `false`, а у `string[]` — пустые: такая ячейка печатается как пустая
  строка.
- Длину массива после создания поменять нельзя: в `ammo` всегда три ячейки.
