# Тип char — один символ

Символ, взятый из строки по индексу, — уже не строка, а значение типа `char` («чар», от
английского character — «символ»). В `char` лежит ровно один символ, и пишут его в
**одинарных** кавычках:

```csharp
using System;

string hero = "Артур";
char first = hero[0];
char grade = 'S';
Console.WriteLine($"Инициал: {first}.");
Console.WriteLine($"Ранг: {grade}");
Console.WriteLine(first == 'А');
```

На экране:

```text
Инициал: А.
Ранг: S
True
```

- `'S'` — символ, а `"S"` — строка из одного символа. Для C# это разные типы: `char c = "S";`
  не скомпилируется — ошибка CS0029, не тот тип.
- В одинарные кавычки помещается ровно один символ: `'ab'` — ошибка CS1012, слишком много
  символов.
- Символ строки можно прочитать, а заменить нельзя: `hero[0] = 'Б';` — ошибка CS0200. Строку
  вообще нельзя изменить — только заменить целиком другой строкой.

Перебрать строку можно циклом `for` до `hero.Length` — как массив: `hero[i]` на каждом шаге —
очередной символ.
