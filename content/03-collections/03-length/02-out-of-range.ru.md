# За границей массива

Что будет, если попросить элемент, которого нет?

```csharp
using System;

int[] wave = { 30, 45, 60 };
Console.WriteLine(wave[3]);
```

Компилятор эту программу пропустит, а при запуске она остановится с ошибкой
**IndexOutOfRangeException** — «индекс вне границ». В массиве три элемента, их индексы 0, 1 и 2,
а индекса 3 нет.

Ошибку, которая случается не при компиляции, а во время работы программы, называют
**исключением**. Платформа объяснит его по-русски и покажет строку, где программа упала.

Чаще всего за границу выходят, когда считают с единицы: «третий — значит `wave[3]`». Помни:
последний индекс на единицу меньше длины.
