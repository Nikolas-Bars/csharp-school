# Length — сколько элементов

Сколько элементов в массиве, показывает `Length` (по-английски «длина»). Его пишут через точку
после имени массива:

```csharp
using System;

string[] loot = { "монета", "кость", "кольцо", "зелье" };
Console.WriteLine(loot.Length);
Console.WriteLine(loot[loot.Length - 1]);
```

На экране:

```text
4
зелье
```

Элементов четыре, а индексы — от 0 до 3. Поэтому последний элемент любого массива —
`loot[loot.Length - 1]`. Выпадет больше лута — код менять не придётся.

`Length` — не метод, круглые скобки после него не ставят: `loot.Length`, а не `loot.Length()`.
