# Список — рюкзак, который растёт

Длину массива задают один раз. А в игре лут приходит и уходит: в рюкзак попал меч — предметов
стало больше. Для этого есть **список** — `List`. Он похож на массив, но может расти и уменьшаться.

```csharp
using System;
using System.Collections.Generic;

List<string> bag = new List<string>();
bag.Add("меч");
bag.Add("зелье");
Console.WriteLine(bag.Count);
Console.WriteLine(bag[0]);
```

На экране:

```text
2
меч
```

- `using System.Collections.Generic;` подключает набор коллекций (collections — наборы
  значений), где есть `List`. Без этой строки компилятор не узнает слово `List`. Пиши её
  второй, после `using System;`.
- `new List<string>()` — новый пустой список. Круглые скобки здесь обязательны. Если сразу
  перечисляешь элементы в `{ }`, скобки можно не писать — это на следующем экране.
- `bag.Add("меч")` — метод списка: кладёт элемент в конец.
- `Count` — сколько элементов в списке сейчас. У массива это `Length`, у списка — `Count`.
  `Count`, как и `Length`, пишут без скобок.
- Индексы — как у массива: с нуля, `bag[0]` — первый элемент.
