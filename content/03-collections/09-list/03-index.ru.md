# Индексы в списке

Перебирать список можно и через `for` — только до `Count`, а не до `Length`:

```csharp
using System;
using System.Collections.Generic;

List<string> bag = new List<string> { "меч", "щит" };
bag[1] = "зелье";
for (int i = 0; i < bag.Count; i++)
{
    Console.WriteLine($"{i + 1}. {bag[i]}");
}
```

На экране:

```text
1. меч
2. зелье
```

- Записать по индексу, как `bag[1] = "зелье"`, можно только в элемент, который уже есть. Список
  от этого не растёт — растёт он только через `Add`.
- Индекс за границей у списка тоже останавливает программу. Ошибка называется
  **ArgumentOutOfRangeException**, но смысл тот же, что у массива: такого элемента нет. Пока в
  `bag` два элемента, `bag[2] = "ключ"` остановит программу.
