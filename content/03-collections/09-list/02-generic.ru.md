# Что значит `<string>`

В угловых скобках `< >` пишут тип элементов: `List<string>` — список строк, `List<int>` —
список целых чисел. Тип, в который подставляют другой тип, называют **обобщённым**. В
справочниках пишут `List<T>`: `T` — место, куда подставляется тип элементов.

Как и в массиве, все элементы списка одного типа: в `List<int>` строку не положить.

Список можно сразу создать с элементами, а перебирать — так же, как массив:

```csharp
using System;
using System.Collections.Generic;

List<int> wave = new List<int> { 30, 45, 60 };
wave.Add(80);
foreach (int hp in wave)
{
    Console.WriteLine(hp);
}
```

На экране:

```text
30
45
60
80
```
