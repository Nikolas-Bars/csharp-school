# Remove и RemoveAt

Убрать элемент из списка можно двумя методами:

- `bag.Remove("зелье")` — убрать элемент с таким значением. Если таких несколько, убирается
  первый. Если такого нет, ничего не происходит.
- `bag.RemoveAt(0)` — убрать элемент с таким индексом.

```csharp
using System;
using System.Collections.Generic;

List<string> bag = new List<string> { "меч", "зелье", "щит", "зелье" };
bag.Remove("зелье");
bag.RemoveAt(0);
foreach (string item in bag)
{
    Console.WriteLine(item);
}
```

На экране:

```text
щит
зелье
```

После удаления элементы сдвигаются: убрали первый — второй стал первым, а `Count` уменьшился на 1.

Не добавляй и не удаляй элементы внутри `foreach` по этому же списку — программа остановится
с ошибкой:
`foreach` не умеет идти по списку, который меняется у него под ногами.
