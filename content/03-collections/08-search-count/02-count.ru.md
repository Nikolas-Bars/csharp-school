# Сколько таких?

Подсчёт — как в модуле «Циклы»: прибавляют не элемент, а единицу, и только когда условие верно:

```csharp
using System;

int[] wave = { 35, 90, 20, 75, 60 };
int strong = 0;
foreach (int hp in wave)
{
    if (hp > 50)
    {
        strong++;
    }
}
Console.WriteLine($"Сильных врагов: {strong}");
```

На экране:

```text
Сильных врагов: 3
```

Это счётчик находок (не путай со счётчиком цикла `i`): он начинается с нуля и растёт на 1 с
каждой находкой.
