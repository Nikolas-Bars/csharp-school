# Сумма элементов

Сумму в цикле считают так же, как в модуле «Циклы», только прибавляют элементы массива.
Копилка — снаружи: переменную с нулём заводят **до** цикла, а в цикле добавляют к ней очередной
элемент:

```csharp
using System;

int[] coins = { 15, 40, 5, 20 };
int total = 0;
foreach (int c in coins)
{
    total += c;
}
Console.WriteLine($"Всего монет: {total}");
```

На экране:

```text
Всего монет: 80
```

- `total` заводят до цикла. Если завести её внутри фигурных скобок цикла, она будет снова
  становиться нулём на каждом шаге, а после цикла её не будет видно вовсе — как на экране
  «Копилка — снаружи» (модуль «Циклы», урок «Сумма и счётчик»).
- Без `= 0` программа не скомпилируется: прибавлять к переменной, в которой ещё ничего нет,
  нельзя.
- Сумму печатают после цикла, когда сложены все элементы.
