# for или foreach

`foreach` только читает элементы. Изменить элемент массива через переменную цикла нельзя —
компилятор не пропустит:

```text
foreach (int hp in partyHp)
{
    hp += 10;   // ошибка: переменную цикла foreach менять нельзя
}
```

Как выбрать:

- нужно просто посмотреть на каждый элемент — `foreach`, так короче;
- нужен индекс (номер места) или нужно изменить элементы — `for`.

Внутри `foreach` можно писать что угодно: условия, вычисления, вывод.
