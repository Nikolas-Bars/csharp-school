# foreach — для каждого

Когда индекс не нужен, перебирать проще циклом `foreach` («для каждого»):

```csharp
using System;

string[] items = { "меч", "щит", "зелье" };
foreach (string item in items)
{
    Console.WriteLine(item);
}
```

На экране:

```text
меч
щит
зелье
```

Читается так: «для каждого `item` из `items`» (`in` — «в», «из»). На каждом шаге в переменную
`item` попадает следующий элемент — от первого до последнего.

Ни счётчика, ни `Length`, ни индексов — выйти за границу массива невозможно.

Тип переменной цикла совпадает с типом элементов: у `string[]` — `string`, у `int[]` — `int`.
